## 2. 缺陷清单（来自旧记录 + 本次实测）

1. 从未做过真机听测：README-GROKBOT 写明原生证据视频只有视频轨、没有音轨；sfx-v2 的 121 项回归全部是模拟 PAL，真实微信播放、切后台、来电打断都没验收。
2. BGM 循环接缝风险：MP3 编码自带首尾填充，48 s 曲子循环时可能出现短暂空隙；规格要求 60–90 s 无缝循环，96–128 kbps。
3. 全游戏只有一首 BGM（标签 "Forest Match v3 — Meadow Tide"），规格要求房间、潮汐、草甸、天空四首，外加三区环境声和房间环境声。
4. 缺海浪、海鸥环境声（场景已有海和海鸥动画）。
5. 缺鼓励音。注意规格原文写"不新增配音"，真人或合成语音的 Great/Amazing/Awesome 需要 Funning 拍板；不用人声的话可以做成音效加文字飘字。
6. 响度不平衡：SFX 峰值 -1.6 到 -2.2 dBFS，解码后有削波风险；BGM 平均 -29.4 dB 再乘 0.4，比音效低大约 20 dB，大概率听不清，需要听测后统一响度。
7. 采样率不统一（BGM 32 kHz、SFX 44.1 kHz），会多一次重采样，问题不大但可顺手统一。
8. 素材缺来源 / 许可 / hash / 循环点清单（规格要求每个素材都有），我没有在交接包里找到。
9. sfx_level_clear 尾部 0.35 s 静音，白占时长和声道席位。

## 3. 修复清单（按优先级）

- P0 真机听测：等 Grok Bot 在 Mac 上跑通构建后，录一段带音轨的微信开发者工具 / 真机视频，验 BGM 起播、循环接缝、消除连击、过关、宝箱、切后台恢复、来电打断。
- P0 响度统一：SFX 归一到真峰值 -3 dBTP 左右，BGM 提升到与 SFX 平均差 8–10 dB，保留 0.4 默认音量或改默认值，听测后定。
- P1 BGM 无缝循环：重做或重新编码，循环点对齐，必要时改用 AAC 或在代码里做首尾交叉淡化（只在音频层，不影响画面）。
