# 第五场景「雪山风铃山口」声音概念（Voice bot，2026-10-22，概念稿，未接入游戏）

气质：高、冷、空，但是安静、治愈。风是主角，可是从不吓人：没有呼啸的尖哨，没有急促感，2–6 kHz 不突出。风铃是“风被看见”的那一下。

## 1. 风的四层（底床 / 点缀 / 地标的思路，与 scene-sound-design.md 一致）
| 层 | 内容 | 频段 | 动态 | 运行时建议 |
|---|---|---|---|---|
| 远处高空风 | 山脊上方持续的细风，带一点混响尾 | 700–2000 Hz，带通，-12 dB | 很慢的起伏（20–30 s 周期） | bed 循环，vol ≈ 0.35 |
| 山口阵风 | 从垭口穿过的阵风，一阵 6–10 s，起落都缓 | 250–1600 Hz，700 Hz 啸音压 -5 dB | 间隔 12–25 s，淡入 ≥2 s | scatter，左右 ±0.5 |
| 近处低鸣 | 山体 / 雪檐下的低频涌动，给空间“重量” | < 180 Hz | 几乎不变 | bed，vol ≈ 0.4（手机外放基本听不到，耳机里托底） |
| 雪沙 | 细雪掠过雪面的沙沙声 | 6.5–10 kHz，非常轻（-30 dB） | 随阵风轻微抬起 | bed，vol ≈ 0.15；**不要**落进 2–6 kHz |

## 2. 风铃音色（两个方案，都用真实录音）
- **A 金属管风铃**（Windchime.ogg，公有领域）：音头柔、尾巴长（自然衰减 6–8 s），最强分音 ~1023 Hz，整体上移 +39 音分落到 C6。偏“清亮、安静”，和天空之城玻璃风铃区分开，比它更暖。试听 `02_snowpass_demo_metal_chime_28s.mp3`。
- **B Koshi 风铃**（Windglockenspiel.Koshi.ogg，CC0）：竹筒 + 金属棒的音色，音头更软、空气感更强，最强分音 ~869 Hz，上移 +22 音分落到 A5。偏“木质、温和”。试听 `03_snowpass_variant_koshi_chime_28s.mp3`。
- 共用处理：HP 300 Hz、LP 6.5 kHz、3.5 kHz 处 -5 dB 去刺、三次短回声做出山口回响；稀疏（平均 8–15 s 一组，每组 1–3 声）。
- 和共同主题「风起」（M1 = 5 1' 2' 3' 2'）的关系：雪山口定 C 大调（湖畔 F 大调的属调，旅途上自然“往上走”）。M1 在 C 调是 G C D E D。真实风铃是不和谐分音，整段移调只能对齐主分音。**定稿做法**：从录音里切单击，逐个重采样到 G5 / C6 / D6 / E6 四个音（各 1 个文件，单声道 32 kbps，约 4×20 KB），运行时随机挑音，偶尔（≈1/6 的概率）按 G-C-D-E 顺序轻敲一次，就是「风起」的影子。
- 推荐：A 做山口地标风铃（离得近、清楚），B 做远处散落的点缀；如果包体只留一套，选 A。

## 3. 试听（previews/Voice-bot/b15-lakeside-l13-16/）
- `02_snowpass_demo_metal_chime_28s.mp3` 四层风 + 风铃 A，28 s，-21 LUFS。
- `03_snowpass_variant_koshi_chime_28s.mp3` 四层风 + 风铃 B。
- `04_snowpass_wind_layers_only_28s.mp3` 只有风（检查风本身够不够安静）。
- 开头 3 s 淡入，结尾 4.5 s 淡出（风铃尾巴自然衰减，不硬切）。

## 4. 素材（真实录音，详见 docs/audio-credits.md）
- 风：Howling_wind.ogg，Tvabutzku1234，CC0（Wikimedia Commons）。三个不同片段分别做低鸣（降一个八度 + LP 180 Hz）、阵风、高空风。
- 雪沙：合成粉噪声（自己做，CC0），只占 6.5–10 kHz。原录音是 16 kHz 采样，没有这个频段。
- 风铃 A：Windchime.ogg，stephan，公有领域。风铃 B：Windglockenspiel.Koshi.ogg，Membeth，CC0。

## 5. 包体预估（定稿）
风 bed 2 条循环（32 s，单声道 24 kbps ≈ 2×96 KB），阵风 3 个单发（≈3×30 KB），风铃 4 个音（≈80 KB）。合计约 360 KB。可以再省：低鸣层和雪沙层合成一条 bed。
