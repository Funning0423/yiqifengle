## 二、区域过渡
- 原则：**环境声先行，配乐后接**。离开场景时 BGM 2.5 s 淡出，新环境层 1.5 s 淡入，新 BGM 延迟 2–3 s 再 3 s 淡入；永远不硬切。
- 小岛→草原：海风层交叉为草地风；吉他保留，作为两区的共同乐器。
- 草原→天空之城：上升音效后只剩高空气流 4 s，钢琴单音 A 起句。
- 天空之城→湖畔（热气球降落，见 07 小样）：d 小调到 F 大调为关系大调，过渡无需转调句。
- 湖畔→雪山：湖水淡出，风层由低到高逐层加入；第一声风铃 = 动机首音 G。
- 雪山→灯塔海岸：C→E♭ 用一个持续的 G 音（两调共同音）做桥。
- 灯塔→森林小镇：远浪→溪流；拨弦低音变为 6/8 吉他。
- 森林小镇→终章：手风琴最后一个 A 音延长，作为终章 C 大调的引入（V/V）。

## 三、终章结构（小节表，72 bpm，4/4，每小节 3.33 s）
| 小节 | 调 | 内容 |
|---|---|---|
| 1–2 | C | 只有风；风铃单音 G、C（雪山回声） |
| 3–4 | C | 钢琴进入，3/4 感的分解和弦（天空之城回声） |
| 5–6 | C→G | 竖琴琶音（湖畔），第 6 小节 D7 转入 G 大调 |
| 7–8 | G | 手风琴持续和弦（森林小镇），吉他扫弦轻入（小岛/草原） |
| 9–12 | G | 全体陈述主题 **D G A B A**，弦乐+长笛+竖琴低八度，第二次加钢片琴高八度（灯塔） |
| 13–14 | G | 乐器逐个退出，长笛独奏末句 **E D B D**（落在 G 大三和弦之上） |
| 15–16 | G | 只剩柔风 + 一声风铃 G，自然衰减到静音（≥4 s 尾音） |

## 四、包体建议
- BGM：**48 kbps 立体声 mp3**（或 64 kbps mono），单曲 30–70 s 可循环，循环点在小节线上，尾音写进下一轮开头。
- 环境声 / 一次性声：**32 kbps mono**，环境循环 ≤ 20 s。
- 复用优先：风铃一次采样复用为雪山全部音高（运行时变调 or 预渲染 5 个音）；风层在雪山与终章共用；湖畔 13–16 关已 0 字节复用。
- 终章不另做长 BGM：优先由各区已有素材的短乐句（每段 ≤ 8 s，48 kbps）拼接，预估 ≤ 250 KB。
- 每个新区域音频总预算建议 ≤ 400 KB，放在各区域分包里。
