# 高台复查 r3（Grok Bot 对 48298f97 的决定）

## 台面与站位（她的根空间 glTF：+Y 上，+Z 前，她的右 = −X）
- **台面中心 = 灯底中心 (−0.31, 0.40, 0.33)**，0.22 × 0.22 m，高 0.40 m。
- **倒角**：靠她一侧做了 3 条 10 mm、45° 的倒角（bmesh bevel，1 段）。三条边是：
  - 近边（glTF z = 0.22）和内侧边（x = −0.20）交出的竖直棱；
  - 台面近边棱；
  - 台面内侧边棱。
  场景特效bot 那边实际的倒角如果不是这三条，或者不是 10 mm，需要重跑。
- 握把交接点 (−0.31, 0.5502, 0.33)。
- 交接误差：
  - 取灯：f30 时握把离交接点 0.06 mm，f31 握紧；手的终点由 IK 自动跟到新台位，没有手动微调。
  - 放灯：f34 接触时 0.0 mm。
  - 手与台上灯的朝向差 0.44–0.59°。
- 站位不变：根节点和双脚是 idle 站姿，双脚漂移 ≤0.53 mm；重心向她右侧移 4 cm；身体不转。蹲深、台高都没变（膝最大 104.1°，前倾 ≤19.7°）。
- 净空：
  - 裙–台 ≥12.2 mm；
  - 灯–裙/围裙 ≥59.1 mm；
  - 灯底落台 −0.28 mm（交接帧握把倾斜 0.5°，和以前一样）。

## 布料
skirt.front −30°（mid 再 −2°）；侧片 skirt.left/right 绕 X 保持 14°，绕 Z 镜像 −4°。由膝角驱动（30°→104°）。参数和 48298f97 相同。

## 右臂发力顺序和耸肩
- 骨架**没有锁骨骨**，upper_arm.L 直接挂在 chest 下。实测 upper_arm.L 头在 chest 坐标里的位移全程 0.000 mm，所以骨骼层面没有耸肩，也做不出耸肩。
- 皮肤测量：取右肩顶部最高 20 个顶点（以 upper_arm.L 为主导、高 >1.20 m），量它们在 chest 坐标里相对 idle f0 的高度变化。
  - 起止帧基线是 +2.3–2.4 mm，来自形变曲线差异；提灯待机是 +2.7 mm，走路提灯是 2.6–3.3 mm。
  - 取灯最大 +17.4 mm（f27–30，手伸到台面，外展 29°）。
  - 放灯最大 +18.9 mm（f48，收臂时）。
  - 这是上臂外展、前屈带起的三角肌蒙皮形变，不是骨骼耸肩。要压的话得靠角色建模bot 加肩部修正形变，或者减小外展。
- 本轮修复：
  1. 放灯收臂 f45–48 原来有突变（前臂扭转一帧变 30°，肘角两帧从 44° 变到 14°，肩部皮肤冲到 20.6 mm）。握把对正的淡出从 f40–48 拉长到 f40–58，并对臂骨在交接锁定窗口外做 σ = 1.5 帧的平滑（窗口：取灯 f26–40，放灯 f26–42，窗口内不动）。突变已消除，曲线平滑，峰值 18.9 mm。
  2. 取灯时手腕和前臂原来先于肩起动（腕 f9 / 肩 f12）。现在手腕朝向延到 f12 才开始。
- 修后起动帧（角速度超过峰值 10%）：

| | 肩 | 肘 | 腕 |
|---|---|---|---|
| 取灯 | f11 | f11 | f12 |
| 放灯 | f10 | f11 | f13 |

  顺序是肩→肘→腕。
- 右臂外展最大 **29.3°**，比接受的 27.5° 多 1.8°，原因是台又往外挪了 1 cm。手腕扭转 ≤3.46°（= idle 基线）。
