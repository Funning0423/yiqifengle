# 高台取灯 / 放灯（角色动画bot，2026-10-22）

依据：Grok Bot 拍板 ②（高台半蹲，地面深蹲版不做）、灯擦膝改为"先竖直提起再收臂"、put_down 单独做（不倒放）；以及新程序摆（握把跟手，灯身铰链摆）。

## 1. 高台参数（她的根空间，glTF：+Y 上，+Z 前，她的右 = −X）
- **高 0.40 m**（30–40 cm 里取上限：同样够得到，膝最大屈 104°、髋最低 0.69 m，比 0.38 m 少蹲 2 cm；布料穿模的起点由膝角决定（约 30°），高度在 30–40 cm 内变化不会消除它，所以选蹲得最浅的）。
- **台面 0.22 × 0.22 m**，长方体（木箱/石墩），台面水平，台边与她根空间轴对齐（朝向 yaw = 0，正面对着她）。
- **台面中心 = 灯底中心 = (−0.20, 0.40, 0.36)**：她右前方，右脚前约 0.30 m、身体中线右 0.20 m。台近边 z = 0.25、内边 x = −0.09。
- 站位：取/放灯时她面向台子正前方站定（就是她的根节点位置，双脚 idle 站姿）。台到裙子最近 22.7 mm，到膝/腿 0 接触。
- 与梯子（建议值，待爬梯 clip/镜头锁定）：梯子在台的**右侧**（她的右手边，−X 方向），梯脚中心距台中心 ≥0.45 m，即根空间 x ≤ −0.65、z ≈ 0.36；台在她和梯子之间，放灯后她向右转 90° 走两步到梯前。爬梯起点站位由爬梯 clip 决定；put_down 结束 = 普通 idle f0，可直接 crossfade 进走路/转身走到梯前。梯子精确位置等爬梯 clip 和运镜bot 的镜头定了再锁。

## 2. lantern_pick_up_stand（2.067 s，62 帧+1）
- f0–4 静止；f2–12 重心微移到左腿 9 mm；f4–24 屈膝下蹲（先屈膝，前倾只在蹲深 >30% 后才起，最大 19.7° ≤30°，任何帧都不直腿弯腰）；右手 f8–27 沿外前方弧线伸到握把。
- f26–31 手型合拢，**f31（t=1.0333 s）交接**：socket 与台上灯握把重合 0.0 mm，手-刚性握把方向与台上灯方向差 0.54°。
- f31–40 **灯先竖直提起 12 cm**（离开台面和膝高），f32–56 起身（提起的灯跟着身体一起竖直升），f40–58 再收臂到腰前提灯姿态。
- **结束帧 = idle_breathing_loop_lantern f0**（逐骨精确相等，收尾前偏差 0.00°）。
## 3. lantern_put_down_stand（2.333 s，70 帧+1）——单独制作，不是倒放
- f0–10 预备：重心移到左腿（髋 +18 mm）、低头看台面，灯仍提着；f8–30 屈膝下蹲，同时手把灯送到台面正上方 12 cm；f26–34 **竖直放下**；**f34 接触**（t=1.1333 s）；f34–40 手松开；f40–46 手离开握把上抬 3 cm；f40–64 起身，右臂回到普通 idle 垂臂；f50–68 重心回中。
- **结束帧 = idle_breathing_loop f0**（精确），可接 walk_start / 转身走向梯子（爬梯前姿态 = 普通站姿）。
## 4. 曲线（交接帧对齐台面）
- lantern_hold_R：pick `[[0,0],[0.8667,0],[1.0333,1],[2.0667,1]]`（f31 握紧 = 灯离台那一帧）；put `[[0,1],[1.1333,1],[1.3333,0],[2.3333,0]]`（f34 灯底触台面那一帧仍为 1，之后 0.2 s 松开）。
- lantern_settle（新，供程序摆用）：pick `[[0,1],[1.0333,1],[1.3333,0],[2.0667,0]]`；put `[[0,0],[0.8667,0],[1.1,1],[2.3333,1]]`。=1 时铰链角收为 0（手稳住灯身），保证离台/落台那帧灯身竖直、不跳。
- 详见 `lantern_stand_meta.json`，代码挂接见 `INTEGRATE.md`。

## 5. 新程序摆（铰链式）——这次一并改
- 握把 **刚性跟 socket.lantern**（跟手），**握把相对手掌转动 = 0**（实测全部帧 0.0000°）。
- 只有提环以下的灯身绕握把轴摆（1 自由度铰链），软限幅 ±8°，挂点不变。
- 发现：直接让握把跟手，在 9 段提灯 clip 里灯会整体歪 38–47°（手骨方向本身不竖直）。所以给 socket.lantern 加一个固定局部旋转（43.08°，= 旧"世界下垂"模式下灯相对手的平均方向），手-局部四元数 xyzw = (−0.78587, 0.05101, 0.18423, 0.58811)。这需要角色建模bot 把它写进 socket 节点，指根以这个方向微调。
- 9 段提灯 clip（lantern_v2）已用新摆法重跑：**1618 帧（含 14 段 crossfade、最大风两相位）穿插 0，灯-布料最小间隙 39.0 mm**（旧 39.7）；压力测试（铰链每帧取 ±8° 中更靠身体一侧，1290 帧）0，最小 25.8 mm。灯身相对竖直最大 11.1°（转身时手腕带动，握把不跟重力，这是新方案的固有效果），摆角 ≤8°。结果在 `../qa_hinge/`。

## 7. 动作自查
- 双脚漂移：dense 0.0 mm；压缩后 pick 0.60 mm、put 0.57 mm（腿链用 LEGTOL 0.04° 压）；crossfade ≤0.47 mm。put→walk_start 的 40 mm 是 walk_start 自身迈步，不是滑步。
- 膝角每帧变化 ≤8.1°，平滑无突伸。前倾 ≤19.7°。
- 右臂外展最大 21.8°（idle 10.5°；伸手向右前下方，肘朝后下，不外张）；手腕扭转最大 3.32°（= idle 基线，握把对正的扭转全部由前臂旋前完成）。
- 灯摆角 ≤6.9°；离台/落台帧摆角 0。
- 手指×握把（L_HANDR_grip）仍有，最多 331 三角对：这是草案手型（lantern_v1 delta），v3b 手型还没出现在 previews/角色建模bot/accessories/（只有 qa/v3b 的中间数据），所以本轮仍用草案。
