# 高台取/放灯 · 方案① 布料骨"顶起"（skirt.front*）—— **未达标，需要决策**

## 做法
- 只动 `skirt.front`、`skirt.front.mid`（围裙主要蒙在 .mid 上）、`skirt.front.low`、`skirt.front.low.mid`。腿、髋、手臂未动。
- 骨架里**没有 apron\* 骨**。围裙蒙在 skirt.front.mid / skirt.front / skirt.front.low / hips 上，所以"围裙幅度略大"只能靠 .mid 比 .front 多转一点来做。8 mm 层间距只能交给角色建模bot 的形变。
- 驱动方式：k = 两膝屈角较大者；x = clamp((k−30)/(104−30))，x' = 1−(1−x)^γ，w = smootherstep(x')。每根骨在原 clip 旋转上右乘"绕骨局部 X 转 A_b·w"。烘成 30 fps 的 LINEAR 通道。
- 参数先在 17 个代表帧上做坐标下降，再对全部 197 帧（两段动作 + 9 个过渡）逐帧做 QA。
- 穿入深度只在相交三角对的局部计算：取内层顶点到外层面（法线背离骨盆）的距离，不设距离窗。

- A 比较折中，三项、外观、新增碰撞都不达标。
- 搜索中途的结果（加重"新增碰撞"惩罚）：碰撞降到 157 对时，腿穿入回升到 61 mm。
  - 结论：右手伸向台面的路径（pick 第 13–15 帧、put 第 15–17 帧提灯段）和高台本身，正好占着前片要让出来的空间。
  - 只靠 front* 骨、手臂不动，做不到"≤15 mm + 不新增碰撞 + 自然"三者同时成立。
- 手握把（顶点口径）在这些帧仍为 0.50 mm。

## 需要决策（任选或组合）
1. 加入 skirt.left/right(.low) 一起参与，让前片别整片翻起：两侧跟着收，减少侧面露腿。这超出当前授权范围。
2. 半蹲的中段（膝角 40–90°）交给角色建模bot 用形变"贴腿"。骨骼只做深蹲段的小角度（约 −30° 以内），目标放宽到骨骼段 ≤40 mm，剩下的由形变消掉。
3. 微调右手取放路径：手往外侧多走 3–5 cm，避开前片。这需要放开"手臂不动"。
4. 改 stand 站位：高台再往右外侧挪约 10 cm，减少台×裙。这需要场景特效bot 配合。
