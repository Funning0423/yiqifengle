## 自查（v2：按 Funning 棋盘原则复审后重做）

**Funning 审出的四条问题，均已修掉：**

1. **托盘角钉**
   - 问题：四角有圆钉，违反 Funning 原则。
   - 处理：湖畔托盘去掉了四个角钉，L13、L16 和夜间版都已重出。
2. **托盘饱和、宽、重，抢焦点**
   - 问题：v1 是饱和的湖青漆木（#86c3bf 一带，色度 C\* 20.8），边框又宽又重。
   - 处理：
     - 改为沿用草原的浅木色块，再用一个色调材质（M_env_palette_lake_tray：色相 +0.17，饱和度 ×0.42，明度 ×1.06）往灰绿 / 湖青方向偏。
     - 边框截面收窄约 40%，高度压低 32%，底板外沿从 +0.62 收到 +0.40。
     - 实测边框色 #b4c9b6，Lab (79.2, −11.2, 7.4)，色度 C\* 13.4，比草原框（C\* 21.7）更浅、更淡。
     - 和草原、天空的色差仍有 20.0。
   - 遗留：色调材质是在共享色板上套了一个 HSV 节点，没有新增贴图。如果 Cursor 那边要求严格只用色板里的原色，可以把这个 tint 烘焙进一张独立贴图。
3. **格子淡紫蓝，像蓝莓，偏冷偏脏**
   - 处理：格子改为草原格子色块套色调材质（色相 +0.25，饱和度 ×0.35），得到浅湖色 #cee2df / #c8ddd8。
   - A/B 两格之间 ΔE 2.1，和草原的 2.4 相当，对比很低；和蓝莓的色相、明度都拉开了。
4. **睡莲和叶子棋子眯眼易混**
   - 处理：
     - 睡莲改用调色板第 2 行暗端（橄榄蓝绿，约 #576f63），明度压低。
     - 厚度从 0.045 降到 0.022，中间鼓起从 0.05 降到 0.012，让它贴格子。
     - 叶缘加一圈浅水，叶面加一道高光弧，去掉了花苞。
   - 结果：灰度均值睡莲 118、叶子 134。眯眼看时，睡莲是「暗色圆片加浅色圈」，叶子是「亮绿尖叶」，可以分清。

**其余各项：**

- **对比度**：HUD 没有改。白天标题 6.86、步数 7.05、道具角标 8.3；夜间 5.10 / 5.14 / 6.06，都 ≥ 4.5。空道具位的「+」号 r6-fix 后为 4.06 / 3.47（原 2.87 / 2.58），见文末 r6-fix。
- **焦点**：现在托盘框色度 C\* 13.4，低于棋子（C\* p50 ≈ 31）。灰度和眯眼图里，托盘已经退到背景层。
- **夜间**：遮罩用的是软过渡，空道具位保留，托盘外沿没有亮边。

## r6-fix（分支 ui/r6-lakeside-fix，基于 c7914d43）

### ① 背景色对不上湖畔场景 → PASS
- 根因：湖畔背景也走了 `boardpost.background` 的处理（模糊 7.5、饱和度 ×0.72、对比度 ×0.78、叠 32% 白雾 #f0f4ee），湖水 83/128/128 被洗成 150/170/163。离线渲染本身的偏差是次要的。
- 改法：新增 `tools/lake_bg.py`。白天背景直接取引擎机位 graded 参考（`ENGINE_COLOR_REFERENCE/engine_cam_r5h3/ref_390x844_graded.png`，即水、岸、天空的实际配色），缩放到 750×1624，只加 3px 高斯模糊让背景退后，不加元素。
  - `compose_region.py` 对 lake 区域不再叠 boardpost 那层白雾。
  - 夜间背景由白天逐通道乘 (0.30, 0.40, 0.56)，再抬暗部 (+6, +10, +22) 得到。
- 实测（`reference/sample.py`，背景放大到 780×1688）：
  - 白天 10/10 个点都在 ±12 以内，实测最大偏差为桥栏杆 −10（bridge_rail_top −10/−4/−2；本行原写「最大偏差 4」有误，已更正）；条纹 std 1.9；当时判 PASS。修改前 0/10，偏差最大 +85。
  - **作废说明（v2）**：这项 PASS 没有信息量——背景本身就是参考图，sample.py 又拿同一张参考图当目标；而且 10 个点里 9 个在托盘下面，玩家看不到。引擎 10 点只适用于引擎实时场景，UI 背景改用可见区域验收（见 v2）。
  - 夜间没有参考图，按 REFERENCE.md 的色相规则判：湖心远水 38/61/80、中部水 31/61/93、近处中部水 33/68/98、近处底部水 42/79/108，四个点都满足 B ≥ G > R，读作暗蓝青；修改前湖心是橙褐色。
- 模糊上限：模糊 4 时桥栏点偏差 −24，FAIL；所以取 3。
- 包体：两张 JPG 合计 59,660 B（原 33,723 B），+25.9 KB。只放湖畔分包，或作为后备。
