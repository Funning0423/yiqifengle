# 地区流程测试包

此入口仅存在于 debug=true 的本地测试构建。debug=false 编译中不创建入口，检查点工厂直接拒绝调用。未上传或发布。

微信开发者工具打开 `task-25/native-package`，等待房间进入可操作状态，点击顶部「地区流程测试」。选择主线 04、08 或 12 的「胜利前最后一步」。首次会正常走出房间并进入该关；棋盘若暂停，先点「继续」。顶部显示「独立测试进度」和最后一次交换的行列。

- 04：交换第 4 行第 3 列与第 5 行第 3 列（索引 23、30）。真实获胜后主线下一关为 05，潮汐挑战开放，草甸需通关 08。
- 08：按顶部实际行列提示完成最后一步，草甸挑战开放；天空挑战需通关 12。
- 12：按顶部提示完成最后一步，天空挑战开放。

宝箱、地区道具、奖励确认、返回、旅程册和挑战入口继续使用现有流程。回到小岛或房间后再次点「地区流程测试」→「退出测试 · 恢复正常进度」。在关卡或天空城时须先返回小岛。退出恢复原主线、R4、R5 端口，不删改或迁移原存储。测试包本身另有新的原生存储隔离前缀，因此这里的原进度指该隔离测试包的原端口；用户正式存档不读取、不带入测试包。

每次检查点使用全新 `dot-region-flow-test-…:` 根，主线/R4/R5 共享该根的各自 lane 与同一个主线 journey。通过原引擎和控制器重放先前合法获胜，只把目标关停在最后一步前，不写伪造全解锁。测试进度不是用户存档；重启测试运行时后须重新选检查点。

「花粉草甸」是挑战棋盘，背景当前仍为小岛，未接入草甸 3D。「天空回声」是挑战；旅程册中的「前往天空城 · 3D 场景」是另一个已有入口。

当前证据为源码、原引擎、临时存储及 Cocos 组件替身回归和本地构建。原生连续按钮回归、手机锁屏、可靠截图/视频仍未验收。模拟 hide/show 不等于手机锁屏。
