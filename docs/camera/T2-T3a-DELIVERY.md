## T2+ (checkpoint 2) — rail / crane / continuous stand-up, T5 light driving, room camera audit

**Dependency:** GGbot T5 final `work/GGbot-t5` **2462ce4** (supersedes 133018c/bf00258), merged as real ancestors
(merge commits on this branch), so `int/v1` (which already contains 2462ce4) sees it as already merged.

Checkpoint-1 interior-weight interpolation is gone; T2+ only *drives* `w` through the T5 API.
