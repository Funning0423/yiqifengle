# T9 岛屿 3D UI 道具（路牌 / 行囊 / 旅程册 / 罗盘 / 海滩棕榈）+ skycity COLOR_1 清理

基于 int/v1 5d66c30。美术来自 work/grokbot 0f28044 `ui-props/`（Draco GLB，全部只用 M_env_palette；路牌灯罩另有 M_signpost_lamp）。

## 运行时
- `world-r2/IslandProps.ts`：宿主。`WorldIntegrationBoot` 在世界 ready 后创建并异步 `load()`（region_island 包内 `ui-props/` 6 个 prefab + 岛的 `M_env_palette` 材质 uuid）。失败 = 保持原平面按钮，不影响启动。
- 所有道具渲染器共享岛上的 M_env_palette 材质资产 → 与岛同一主光 / 环境光 / 昼夜写入（RoomLightingRig 不改，无新增换材质）。唯一的换材质是路牌灯罩：白天 M_signpost_lamp，夜晚 M_env_palette（UV 在调色板自发光行，暖光）。
- 路牌：世界坐标固定在西侧草地（`ISLAND_PROPS.signpost` = (-4.08, 0.127, 0.7)，yaw 5.58°，scale 0.79）。两只立柱落在 `env_island_main` 的草地（调色板第 0 行）上，底面取较高那只立柱的地面高度，较高的那只立柱贴着草地，较低的那只因为坡度高出地面约 3.5 cm。牌面法线与朝向镜头的水平方向大约偏 15°，远景和拉近都能读字。远景投影宽度不超过画面的 22%。立柱处仍有接触阴影 + 两圈涟漪数据（程序网格，海面高度；草地盖住这块 xz，所以涟漪不露在草上）。文字“继续旅程”是 RenderRoot2D 下的系统字体 Label。原 `mainline` WarmButton 仍是命中区与动作（`composition.enterMainline()` 不变），透明，尺寸 = 路牌投影框扩到至少 88x88 逻辑像素（`signpostHitUi`；扩展部分仍完整覆盖路牌，留在 8px 安全边内并避开底排按钮，取离画面中心最远的一块，避免远景里盖住女主）。
- 三个按钮：原 `Island-bag/journal/settings` WarmButton 节点不变（动作不变），透明后作为命中区，按 `propButtonLayout` 放到底排；3D 道具每帧由 `seaAnchor` 放在命中区下方海面上并按像素高度缩放；奶油色圆角标签（Graphics + 系统字体 Label，深棕字）。
- 海滩：只加两棵棕榈（`beach_palm_tall` 西岸草地边 (-3.3, 0.05, 6.6) yaw 60°、scale 0.75（原 (-0.5, -0.30, 9.0) yaw 200° scale 0.9，在 0.46 最近停靠镜头正下方），、`beach_palm_short` 右沙滩）。海鸥/螃蟹/海龟岛上已有（env_anim_seagull_01、env_anim_crab_01 + hermit crab、env_anim_turtle_01），未重复添加。

## 点击订阅 API（给 Voice bot A5）
```ts
import { onPropTap } from './world-r2/IslandPropTaps';      // 也可 IslandProps.onPropTap 或 globalThis.__worldIntegration.onPropTap
const off = onPropTap((target, phase, info) => { /* 播放点击音 */ });
// target: 'signpost' | 'bag' | 'book' | 'settings'
// phase : 'press'   手指在命中区按下（同节点 TOUCH_START）
//         'confirm' WarmButton 接受了这次点击（在区域内抬起、未拖走），动作即将执行；在绑定的动作里、派发前触发
// info  : { blocked: boolean, props: boolean }
//         blocked = 此刻宿主拒绝动作（忙 / 旅程册弹层打开 / 关卡弹层 / 面板禁用），blocked 的 confirm 不执行任何动作
//         props   = 屏幕上是 3D 道具（false = 平面后备按钮）
off();   // 退订（可重复调用）
```
- 真实点击和 T0 注入点击走同一 Cocos 输入路径，同样触发。
- 可能出现 `press(blocked=true)` 之后没有 confirm；press 后手指拖出或取消也不会有 confirm。建议：press 且 !blocked 播按下音，confirm 且 !blocked 播确认音。
- T9 本身不播放任何声音；监听器异常会被捕获并 warn。

## 入场动画（T2+ applyIslandEntrance 序列，rebase 到 int/v1 0f54339 后）
- 路牌模式下 applyIslandEntrance 不再移动/缩放透明的 mainline 命中区（它跟随路牌投影）。底排按钮先入场（原有 0.25 s、三次缓出 `1-(1-x)^3`、24 px 下滑 + 0.94→1 缩放；3D 底排道具跟随 dock 的位移/缩放）。
- 按钮结束后路牌作为同一序列的下一步入场：同样 0.25 s、同样三次缓出；从水下上升 24 px（按路牌处的投影比例换算成米）并淡入（`IslandProps.setSignEntrance`）。淡入期间用共享材质的临时透明副本（同 effect 的 transparent technique，alpha=e），结束即还原共享材质并销毁副本（无持久换材质）；文字用 UIOpacity；涟漪/阴影 alpha 同步乘 e。
- 出发飞往岛（crossing-out）期间与按钮入场期间路牌隐藏；其他方式回到岛（无入场）立即显示。
- mainline 命中区在路牌入场结束后才生效（入场期间尺寸为 0）；无入场时立即生效。运镜bot 相机不变。

## T9n 夜间（Funning 反馈）
- 路牌灯：夜间真实 SphereLight（灯罩前方，路牌局部 (-0.78,1.12,0.42)，暖色 #ffc47a，range 2.6×scale，size 0.06×scale，亮度 = 引擎默认 luminance × 1.6 × 夜间权重，同 RoomLightingRig 灯的 HDR/LDR 安全写法）。`Light.visibility` 只含路牌所在的 user layer bit 0（世界相机已渲染、场景内无其他节点使用），因此 forward-add 只作用于路牌 2 个 renderer（+2 draw call，仅夜间），岛/海/棕榈/按钮不受影响；相机不渲染该层时自动跳过（只剩灯罩自发光）。透明材质（水面网格）不走 forward-add。
- 水面暖色反光：程序椭圆（builtin-unlit "add" technique，顶点 alpha），alpha 0.2 × 灯光权重。路牌文字颜色按权重 #633f21 → #3a220f。灯罩昼/夜材质改在淡入中点（权重 0.5）切换。
- 夜间权重：岛上昼夜是瞬时切换（DayNightContract 只有 0/1，无引擎侧权重）；道具自己用 0.5 s 线性跟随（`approachNight`，dt 上限 0.1 s），灯光再加 smoothstep，首帧直接取当前模式。
- 底排标签：同一权重（`setPropNightWeight`/`propNightWeight`），白天 #f8f2e2/#956737/#633f21，夜间 #9a8f7f/#5e4128/#2b1b0c；对比度白天 8.30、夜间见测试，全程 ≥ 4.5:1。
- Boot、RoomLightingRig、岛材质均未改。
