# T9 岛屿 3D UI 道具（路牌 / 行囊 / 旅程册 / 罗盘 / 海滩棕榈）+ skycity COLOR_1 清理

基于 int/v1 5d66c30。美术来自 work/grokbot 0f28044 `ui-props/`（Draco GLB，全部只用 M_env_palette；路牌灯罩另有 M_signpost_lamp）。

## 运行时
- `world-r2/IslandProps.ts`：宿主。`WorldIntegrationBoot` 在世界 ready 后创建并异步 `load()`（region_island 包内 `ui-props/` 6 个 prefab + 岛的 `M_env_palette` 材质 uuid）。失败 = 保持原平面按钮，不影响启动。
- 所有道具渲染器共享岛上的 M_env_palette 材质资产 → 与岛同一主光 / 环境光 / 昼夜写入（RoomLightingRig 不改，无新增换材质）。唯一的换材质是路牌灯罩：白天 M_signpost_lamp，夜晚 M_env_palette（UV 在调色板自发光行，暖光）。
- 路牌：世界坐标固定（右前沙滩外浅水，离水线约 2.4 m，`ISLAND_PROPS.signpost` = (1.9, -1.15, 13.1)，yaw -20°，scale 1.2；立柱没入海面 0.23 m）。立柱处有接触阴影 + 两圈向外扩散的涟漪：程序生成的扁平网格（顶点 alpha），builtin-unlit technique 3（双面透明、不写深度，同 RoomLightingRig 茶汽），0 资源字节；夜间降低 alpha/换冷色；builtin-unlit 不可用时自动跳过，文字“继续旅程”是 RenderRoot2D 下的系统字体 Label（0 字节字体资源）。原 `mainline` WarmButton 仍是命中区与动作（`composition.enterMainline()` 不变），透明，尺寸 = 路牌投影框（`signpostRectUi`）。
- 三个按钮：原 `Island-bag/journal/settings` WarmButton 节点不变（动作不变），透明后作为命中区，按 `propButtonLayout` 放到底排；3D 道具每帧由 `seaAnchor` 放在命中区下方海面上并按像素高度缩放；奶油色圆角标签（Graphics + 系统字体 Label，深棕字）。
- 海滩：只加两棵棕榈（`beach_palm_tall` 左沙滩、`beach_palm_short` 右沙滩）。海鸥/螃蟹/海龟岛上已有（env_anim_seagull_01、env_anim_crab_01 + hermit crab、env_anim_turtle_01），未重复添加。

## 点击订阅 API（给 Voice bot A5）
```ts
import { onPropTap } from './world-r2/IslandPropTaps';      // 也可 IslandProps.onPropTap 或 globalThis.__worldIntegration.onPropTap
const off = onPropTap((target, phase, info) => { /* 播放点击音 */ });
// target: 'signpost' | 'bag' | 'book' | 'settings'
// phase : 'press'   手指在命中区按下（同节点 TOUCH_START）
//         'confirm' WarmButton 接受了这次点击（在区域内抬起、未拖走），动作即将执行；在绑定的动作里、派发前触发
// info  : { blocked: boolean, props: boolean }
//         blocked = 此刻宿主拒绝动作（忙 / 旅程册弹层打开 / 关卡弹层 / 面板禁用），blocked 的 confirm 不执行任何动作
//         props   = 屏幕上是 3D 道具（false = 平面后备按钮）
off();   // 退订（可重复调用）
```
- 真实点击和 T0 注入点击走同一 Cocos 输入路径，同样触发。
- 可能出现 `press(blocked=true)` 之后没有 confirm；press 后手指拖出或取消也不会有 confirm。建议：press 且 !blocked 播按下音，confirm 且 !blocked 播确认音。
- T9 本身不播放任何声音；监听器异常会被捕获并 warn。
