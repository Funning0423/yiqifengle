## 1. 场景设计原则（Funning 思路 + DESIGN 既定规则）
1. **四季覆盖**：后续场景按 春 → 夏 → 秋 → 冬 → 黎明 → 夕阳 的情绪弧排布，与故事《风会带我去找你》由轻到重再到重逢一致。
2. **世界名胜致敬**：取材真实景区的"地形/氛围/标志性轮廓"，**一律原创低模再诠释**，不复刻任何受版权保护的建筑设计、商标、游戏/动画造型；地标名在游戏内用原创名。
3. **地区结构不变**：沿用 R4–R8 故事地区与关卡 ID（新13–新38），只给每区补"季节 + 名胜灵感"；新增 1 个夏季区以补齐四季（ID 追加，不改存档键）。
4. **活的棋盘**：每区一套边框 / 6 类棋子 / 1–3 只小动物 + 稀有彩蛋（§5.3 规范）。
5. **一区一分包 ≤ 1.0 MiB**；顶点色 + 共享 256² 调色板；模块 instanced 复用。
6. **性能**：棋盘场景 DC ≤ 70（低端 ≤ 40）、三角面 ≤ 70k（低端 ≤ 20k）。
7. **转场**：每区入/出各 1 段 9–13 秒运镜（§4），可跳过（结局首播除外）。

## 4. 各场景要点
### S1 R4 风铃湖畔村·春
- 地标：原创三孔石拱桥（断桥轮廓致敬）+ 柳堤 + 挂满风铃的木屋群；远景桃花点缀用 instanced 面片。
- 机制：风铃格（复用灯标计数）。道具：湖光灯。
- 背景：湖面复用海面 shader 改色；柳枝顶点摆动；窗灯渐亮。
- 资产：木屋模块×3 ≤3k、拱桥 ≤1.2k、风铃 ≤150（instancing）、柳树 ≤400×N、鸭 ≤500。
- 性能目标：DC ≤55 / 低端 ≤35；三角 ≤50k / ≤18k。

### S2 R4.5 竹筏山水·夏（新增）
- 地标：原创喀斯特峰林剪影（3 层视差，单面片顶点色）+ 江面竹筏 + 渔家小屋。
- 机制：**水流格**——指定行每 3 步整体左移一格（轻压力，复用落子平移逻辑）；彩蛋：雨后彩虹倒影。
- 资产：峰林 ≤4k、竹筏 ≤800、水牛 ≤600、鸬鹚 ≤400；江面复用湖面 shader。
- 理由：补齐"夏"，同时给 R4→R5 之间一段水路，减少连续步行转场。
- 风险：+5 关、+0.9 MiB，合计包体 ≈ 25.3 MiB（仍有 ~4.7 MiB 余量）；**需 Funning 批准**，不批准则 S2 降级为 R4 内"夏日支线 3 关"（≤0.4 MiB）。

### S3 R5 秋林铁路·秋
- 地标：原创林中小站 + 石拱高架桥（阿尔卑斯山线弯道桥致敬）+ 红黄彩林。
- 机制：小火车轨道 + 落叶。道具：检票钳。火车模型复用到 T5。

### S4 R6 雪夜观星台·冬
- 地标：圆顶观星台 + 大望远镜 + 极光带（顶点色面片）。
- 机制：冰封棋子、星图。道具：暖手炉。雪人每关多搭一段。

### S5 R7 云海·黎明
- 地标：云海中的奇松浮石（黄山松轮廓原创化）+ 石柱群 + 断风筝。浮石复用 R3 岩石换色。
- 机制：风向、云遮。道具：风哨。

### S6 R8 山丘重逢·终章
- 地标：坡顶两人座大风筝；远景薰衣草条带 + 热气球剪影（≤3 个面片）。山丘复用草甸地形，阿宁复用阿芳骨架。
- 机制：放风筝线，无新障碍；新38 降难。

## 8. 提速方案
1. **流水线并行**：同一时间至多 3 个场景处于不同阶段（概念/白盒/精修），不再一个场景做完再开下一个。
2. **拆小里程碑**：每段 ≤ 3–5 天、产出物可直接看（图/录屏/视频），过一段才进下一段；不追求一次做完。
3. **分工拆解**：场景设计部只负责概念+白盒+地标；棋盘皮肤/棋子由 grokbot-2；小动物与角色由 Oi；音效由 Voice Bot；接入由 GGbot；转场由运镜bot——场景设计部不再独立包揽全部。
4. **复用清单先行**：每个概念单必须列出"复用哪些现有资产"（海面 shader、R3 岩石、草甸地形、火车、阿芳骨架），新建资产只做地标。
5. **每日 check-in（北京时间 / ET 各标注）**：每天固定一次，格式 3 行：昨日产出（附图/录屏路径）、今日计划、阻塞。超过 1 天无产出由 grokbot-2 介入拆任务。
6. **解除阻塞**：M0 分包未完成时，白盒在独立测试场景中做，不等主线合并；包体用 Asset Bundle 单独构建实测。
7. **验收即时化**：grokbot-2 收到概念单/白盒当天给出"通过/改动清单"，Funning 只看精修对比视频做选择。
