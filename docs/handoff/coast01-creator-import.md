## Reusable import/build steps (COAST02–09)
1. Box: sparse worktree from the integration branch; `git apply --3way --binary` the candidate; resolve conflicts by hand.
2. Mac: own dir `~/qfap-coastNN/` (never ~/qfap-buildBAL / ~/qfap-run). Clone; check ≥3 GiB free; no DevTools running.
3. Set userData (bundle / sprite-frame / meshCompress like region_lakeside) in the folder/asset metas only where needed, then run Creator CLI
   `CocosCreator --project creator-build-project --build configPath=tools/build-guard/wechat-release.json` (exit 36 = ok; SIGTERM / mach_port lines are teardown noise). Creator writes all metas.
4. Restore Creator's rewrite of `transport_balloon.glb.meta` (sub-meta c9dd7) before committing; for the guard keep it as a LOCAL-ONLY commit, never pushed.
5. Copy metas back (tar with `COPYFILE_DISABLE=1`, drop `._*`), commit, push.
6. Guarded build: `QF_STAGE_ROOT=… LOG_DIR=… META_ALLOWLIST_BASE=HEAD STRIP_PROBES=0|1 bash tools/build-guard/build-wechat-guarded.sh wechat`.
7. DevTools: one window at a time across bots; keep logs outside shared dirs; `caffeinate -d -u` during the run (display sleep after 3 min freezes the simulator); "模拟器启动失败"/no output = flake, `cli quit` and retry; close by own PID / `cli quit` only.
8. Clean library/temp/build/recordings right after use.
