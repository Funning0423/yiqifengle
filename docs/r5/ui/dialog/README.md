## 3. 名字标签的配色规则

1. **一个角色一种颜色，定死，不随场景变**。色相取角色的标志色：
   - 阿芳：草帽和向日葵裙子的赭黄。
   - 阿宁：海青。
   - 老铆：铜绿。
2. **白字（#FFFBF0）对标签底色的对比 ≥ 4.5:1**。不够就只降明度，不换色相。
3. 不同角色的色相相隔 ≥ 60°，同时出场时也能分清。不用纯红和纯绿（色弱玩家容易混）。
4. 旁白或“风”的独白**不加名字胶囊**，正文改成 #7A6A58，左边加一个 12 pt 的风纹小图标。
5. 夜间：标签底色乘 K_UI，字不变色（和结算页的规则一样）。

| 角色 | 底色 | 白字对比 | HSL |
|---|---|---|---|
| 阿芳 | **#A0620E** 赭黄 | 4.78 | 35° / 84% / 34% |
| 阿宁 | **#2A7B80** 海青 | 4.79 | 183° / 51% / 33% |
| 老铆 | **#5A7A3C** 铜绿 | 4.74 | 91° / 34% / 36% |
| 正文 #5A4636 对奶油底 | A #FFF7E4 · B #FBF2DC | 8.32 · 7.97 | — |

第一版的阿芳用 #B06E12，对比只有 3.99，已经压暗到 #A0620E。新增角色时，按这三步取色：先取色相，再把明度压到对比 ≥ 4.5，最后检查和已有色相的间隔。

## 4. 字体、授权和子集化

| 用途 | 字体 | 授权 | 来源 |
|---|---|---|---|
| 名字（圆体） | **资源圆体 Resource Han Rounded CN Bold**（v0.990） | **SIL OFL 1.1**。可以商用、嵌入、改；不能单独卖字体；衍生版本不能用保留名 “Source” | github.com/CyanoHao/Resource-Han-Rounded（基于思源黑体） |
| 正文（粗黑体） | **思源黑体 Source Han Sans SC Bold**，也就是 Noto Sans CJK SC Bold（字形相同） | **SIL OFL 1.1**，Adobe，保留名 “Source” | github.com/adobe-fonts/source-han-sans 和 notofonts/noto-cjk |

- OFL 允许把字体打进游戏一起发、一起卖，也允许子集化（子集化属于 Modified Version）。条件有三条：
  1. 包里要带版权声明和 OFL 原文。放在 `licenses/fonts/` 下，设置页的「关于」里列出来。
  2. 子集**不要用保留名 “Source” 当主字体名**。建议改名，例如 `QFL Dialog Name` / `QFL Dialog Body`。
  3. 子集也只能按 OFL 分发。
- 动森用的 Fontworks Seurat 和 Rodin 是商业授权，**不用**。
- 站酷快乐体（OFL）偏手写，太俏皮，放在名字里比圆体更“动森”，所以也不用。

**子集化方案（只打包用到的字）**

1. 构建时扫描全部台词、名字和 UI 文案，得到一份 `dialog_chars.txt`。加上标点，再加上 0–9、A–Z、a–z。
2. 用 `pyftsubset --text-file=... --no-hinting` 出 TTF。小游戏的 `wx.loadFont` 吃 TTF；思源是 CFF，出 TTF 时要转成 glyf 轮廓。子集放进分包，不放主包。
3. 名字字体只收角色名用到的字（几十个）。正文字体收台词里用到的字。
4. 文案改了就重跑脚本。CI 里检查“台词里有、子集里没有”的字，发现就报错，不能静默回退到系统字体。

**预估体积**（在本机用这两个字体实测）

| 子集 | 资源圆体 Bold | 思源黑体 Bold |
|---|---|---|
| 只有名字（阿芳、阿宁、老铆、旁白、风，8 个字） | **3.7 KB** | 4.1 KB |
| 这次对比图用到的字（约 60 字） | 18 KB | 19 KB |
| 800 个常用字（估计第一章台词的规模） | 329 KB | 344 KB |
| GB2312 一级 3755 字（全收，不建议） | 1.55 MB | 1.51 MB |

- **建议**：名字用圆体，只收名字用到的字，约 4 KB；正文用思源黑体，收台词用到的字，约 300–400 KB（800 字左右）。合计 < 0.4 MB。
- 现在的包是 20.3 MB，上限 24.6 MB，这个量放得下。
- 如果还想省，正文可以改用系统粗黑体（0 KB，iOS 是苹方，Android 各家不一），代价是各机型字形不统一。这一项要用户来定。
- 简繁还没定。如果要出繁体，正文子集大约翻倍。字体子集等简繁定了再做最终版（REPORT 待拍板第 6 项）。

## 5. 动效思路（只是思路，参数定稿时再细调）

| 动作 | 方案 A | 方案 B |
|---|---|---|
| 出现 | 气泡从下面 12 pt、scale 0.92 → 1，0.18 s backOut(1.4)，α 0 → 1 在前 0.10 s；尾巴和名字胶囊晚 0.04 s 弹出，scale 0.6 → 1，0.14 s | 牌子从下面 8 pt 滑入，0.16 s cubicOut；名字胶囊从左边 6 pt 滑入，晚 0.05 s |

## 6. 和动森有哪些刻意的区别

| 动森 | 我们 | 为什么 |
|---|---|---|
| 气泡边缘是不规则的波浪 | A：规整的大圆角；B：低多边形切角 | 波浪边是动森最有辨识度的一笔，不抄。圆角和切角都和我们岛上的风格对得上 |
| 名字标签**斜插**（约 −5°） | 水平的胶囊；A 骑在框外，B 收在框内 | 斜插也是辨识点，不抄；水平的更“安静”，符合“起风了”克制的调子 |
| 没有尾巴 | A 有一个指向说话人的小尾巴 | 我们是 3D 自由视角，说话人可能不在画面正中，需要尾巴指向他 |
| 框压在画面下方三分之一，宽度接近满屏 | 放在女孩脚下面，离她 ≥ 13 pt，底部再留 16 pt 给安全区 | 竖屏手机，人物占画面比例大，不能压人 |
| 三种字体混排（圆体名字、粗黑体正文、UD 圆体注音） | 只用两种：圆体名字和粗黑体正文，不要注音 | 精简规则；包体 |
| 翻页提示是一个闪烁的三角 | A 是轻跳的橙色圆角三角；B 是青绿色小圆钮 | 颜色取我们自己的强调色（结算按钮的青和金），不用动森的颜色 |
| 打字音效是“动物语” | 很轻的一声“咕”，按角色定音高，可以在设置里关掉 | 不模仿动物语这种标志性音效 |
| 字色深棕 | 深棕 #5A4636（REPORT 里的建议值） | 这一项保留：它本来就是通用做法，而且不用纯黑也是我们的调色规则 |

## 7. 推荐

**推荐方案 A · 海风气泡。** 理由：
1. 一眼能看出谁在说话：框外的名字胶囊加尾巴，3D 自由视角下也能指到人。
2. 和现有的吐司、弹窗是同一家族（奶油色、圆角、柔投影），岛上的整体风格不会分裂。
3. 在两种屏幕上离女孩都有余量（20 / 17.8 pt）。B 是 15 / 14.8，离 13 的下限太近，台词多一行就会越线。
4. 精简：一张九宫格、一个尾巴、一个三角，用 Graphics 画也很便宜。

B 的切角可以作为 A 的“系统提示”变体（不是角色台词时用），这样两种信息的样子有区别。
