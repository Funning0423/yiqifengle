# 过场草案：风铃湖畔 → 第五场景「雪山风铃山口」

运镜bot · b18 定稿（build16）· **只是草案，不实现**。交通方式**按热气球定稿**（概念推荐，复用 `transport_balloon.glb` 和湖畔的系泊、顺风爬升逻辑）。入口点和坐标还没定，等场景特效bot的灰盒出来再填。
参考：`previews/场景特效bot/r5/snowpass_concept/CONCEPT.md`（风铃门：双石柱高 18 m，5 根铃管；风向 109.3°；暂定关卡 17–20）。

## 原则
- **按热气球写。** 三个模块镜头组：A 离开湖畔（在气球系泊点上篮）、B 顺风爬升穿云、C 抵达揭示风铃门（气球落在雪台）。以后要换交通方式，只换 A3、B 组和 C2，见文末的备选表。
- 坐标一律用占位符 `⟨…⟩`，等灰盒出来再填。湖畔这一侧可以复用现有锚点（`lakesideLandingLocal`、`LakesideSceneData` 的系泊点）。
- 动作要自然：机位连续，不做硬切。只在穿云和白场的时候允许一次遮挡转场。只有棋盘视角锁 yaw，过场里 yaw 跟随运动方向。
- 竖屏 390×844 是基准；矮屏（390×520、320×568）保持竖直 FOV，构图主体放在画面中间 60% 的范围内。
- 风向统一：画面里的运动方向顺着 GlobalWind（0.944, −0.330），风是从山口吹下来的，所以旅程是「逆风回源头」。镜头前进方向和风带交叉，不要和风带平行。

## 热气球定稿要点
- **航线：** 复用 `lakesideBalloonPath` 的高度关键帧形状。起点是湖畔系泊点，终点是雪台 `⟨P⟩`，爬升高度按山口高差放大（占位 `⟨ΔH⟩`）。B2 的云层放在航程 45–60% 处。
- **风向：** 航向与 GlobalWind 交叉约 30°，不要顺着风带飞，这样风带能横穿画面。
- **抵达：** 和湖畔一样，镜头先停在门口镜头上，再按她的步行进度混合到雪山棋盘镜头，中间不硬切。
- **待填（灰盒后）：** 湖畔出发点 D（默认就用湖畔系泊点 [9.5, 0.602, 25.6]）、雪台 P、门 G、雪山棋盘镜头。
