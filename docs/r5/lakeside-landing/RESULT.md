# r5 湖边热气球降落镜头：第一版结果（运镜bot）

分支 `cine/r5-lakeside-landing-cam`，从 `cursor/r5-lakeside-reach-66d3`（PR #60，`e9dffc01`）拉出。对应 free-camera SPEC §12。
预览图：`/workspace/yiqifengle/previews/运镜bot/r5-lakeside-landing/`。审计：`tools/lakeside-landing-cam/audit.cjs` → `audit.json`。

**结论先说**：第 9 秒以后（热气球已经离开大树根部），飞行镜头和落地镜头基本满足 HANDOFF §4：离几何 ≥ 2.99 m、零跳变、
女孩全程在画面里、UI 间距 ≥ 62.9 pt、角加速度 79.6°/s²。**没过的地方有三处**，写在 §5：
起飞前 8.5 秒（S6 在大树根里）、11–15 秒有几帧回看天空之城时射线落进南岸禁区、线加速度 3.21 m/s²（上限 3）。

## 1. 现状的问题（e9dffc0 实际运行的样子）
1. 女孩没有被放进篮子：热气球飞走了，她还站在 S6。
2. 旧镜头在终点退化：降落到岸边时 h = 0，镜头直接朝下看。
3. 飞完之后 `RegionJourneyController` 又调用 `world.setCamera(this.camera)`，把出发时的旧机位放回来。
   旧租约没有 `onFrame`，所以这一下跳了 **42.7 m / 73°**。
4. 飞行途中没有调 `lease.progress`，所以湖边的光和雾、棋盘预载都要等到落地才开始。
5. 落地时 yawRad 是 180°，她背对着湖。
6. 起飞点 S6 在大树根里，热气球一开始就穿进树根约 2 m（新旧都一样，见 §5）。

### 2.2 `LAKESIDE_CAMERA_LAYOUT.landing`
**没有改**。E 就是这块屏幕的棋盘机位：`arrivalPose(L.arrival, L.focus, lakesideRouteLanding(L))`，湖本地坐标约 [2.95, 3.58, 31.16]，FOV 约 57°。
它三种尺寸全过：离几何 2.99 m，UI 间距 73.9 / 62.9 / 226.6 pt，南岸坏射线 0，头和胸都不被挡，女孩占画面高 0.24–0.25。
改它会连带改已经批过的棋盘机位，所以飞行镜头直接收进 E，这一镜就和 `LakesideLandingHook`（1 s，LANDING_MATCH .05 m / 10° / 15°）、棋盘接上了。

### 2.3 代码（`RegionJourneyAdapter.prepareLakesideJourney`，loose ES5）
- 改用 `lakesideBalloonFlight(start, shore, E)`，时长和路线都从它取。
- 飞行开始时读一次当前相机，作为起始混合的 from。
- 女孩挂到 `stand_point` 上（本地 y −0.1，yaw 取 girlYawRad），落地前放回原来的父节点。
- 每帧调 `lease.progress(d)`。
- 新增 `onFrame()`，返回最后一帧的镜头，这样控制器不会再把出发时的旧机位放回来。
- `cancelAndReset` 的 yawRad 改成飞行方向。
- `RegionJourneyCore.sampleRoute`：如果落在最后一段，而且离终点不到 1e-9 m，直接返回终点。原因是 96 段累加有浮点误差，落点会差 1e-15 m，`test_lakeside_reach` 要求严格相等。

## 3. 南岸禁区检查（可以量化）
- **禁区**：湖本地坐标 z ∈ (42, 90]，x ∈ [−36, 33]，地面高度 y < 3。范围是地形 LK_terrain 的 x 宽度往南延到天空之城。
- **怎么测**：每一帧在 390×844、360×780、768×1024 下各打一张射线网格，每张 18×39；落地机位用 27×58。
- **判坏**：一条射线，第一个击中的是湖边几何，击中点 z > 42 且 y < 3；或者什么都没打中，但在禁区内穿过湖面 y = 0.58。
- 第一个击中天空之城几何的射线不算坏，单独记作 `skyBlock`：天空之城的地面挡在前面，后面那块看不见。
- 落在禁区外的空洞单独记作 `sideVoid`。
- **结果**：落地机位 0 / 1566；第 9 秒以后，10 Hz 下有 25 帧（大屏 35 帧）不是 0，集中在 11.3–14.8 s，这时镜头在回看天空之城（见 §5）。

## 5. 没过和要拍板的
1. **起飞那 8.5 秒**：S6 在大树根里、贴着树干，正上方没有能放下热气球的地方，往西 13 m 的 [−7, 0.58, 53] 才有。
   所以前 8.5 s 篮子要从树根里升起来，镜头没法同时满足离几何 1.1 m、不被遮挡、看不到禁区。
   建议二选一：把出发点挪到 [−7, 0.58, 53] 附近，让她先走过去；或者请美术在 S6 清出一块。
   出发机位本身（天空之城跟随镜头）在 t = 0 就能看到 45 条禁区射线，那是天空之城地面上的空洞。
2. **11–15 s 回看天空之城**：低处的射线会从天空之城地面的缝里漏进禁区。如果南岸的地面特效补齐了，这几帧就不算问题；否则要把这段的俯角压平一点。
3. **线加速度 3.21**：把 blendInS 调到 7.5 预计能降到 3 以内，但这一版没有再审计。−90° 起始方向要把 blendInMaxFrac 放到 0.4。
4. 落地后热气球停在岸边，会出现在棋盘画面里，要定一下是飞走、收起还是留着。
5. 这些都是离线审计：几何是提交的 GLB（天空之城用 draco 解码，云海、远积云、小云不算碰撞），没在浏览器里看过真机画面。

## 6. 自由视角
- **落地后**：湖边先不开自由视角，按 SPEC §11/§12：`lakeside.enabled = false`，镜头停在 E，也就是棋盘机位。
- **热气球段**：只写进文档，代码里还没有。
  - 水平 ±20°，俯仰 ±10°，围着她胸口转，距离不变。
  - 拖动增益沿用 SPEC 默认。
  - 松手后弹簧回到设计轨道：临界阻尼，ω = 6 rad/s，大约 0.6 s 回到 95%。
  - 回弹时每帧的角加速度要 ≤ 120°/s²，必要时截断。
  - 最后 8 s 的落地混合里逐渐把偏移衰减到 0，保证 t = T 时正好落在 E。
