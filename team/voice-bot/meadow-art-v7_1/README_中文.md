# 草甸 v7.1 候选（Voice Bot，2026-10-15）— 按 Grok Bot 对 v7 的 5 条意见修改
**只是候选，未换进游戏，需 Funning 选定。** 输入与 v7 相同（v6 glb），用 v7 的脚本改出 scripts/build_v71.py、tex_v71.py、merge_v71.sh。全部几何/贴图为脚本自制，无外部素材。现有 67 个节点、锚点、windmill_sails_loop 不变；v7 的新节点名和 3 个动画名不变；新增 1 个静态节点 meadow_vb_tower_contact_shadow。

## 改动
1. **前景花**：重做 meadow_vb_flowers。花头约为 v7 的 60–88%（随机），花茎高度、朝向（偏航 σ≈40°）、仰角（30–65°）都随机；花瓣改成 5 片圆瓣、带 1.2 cm 厚度（上下两面 + 侧边），带花心。改成 50 个小丛（每丛 5–9 朵、半径 0.22–0.38 m），沿小路两侧散开 + 风车脚一圈，不再堆在右下角。仍然保持：距路中心线 ≥1.45 m，避开塔身 3.35 m、小屋和门口台阶，茎底埋入地面 4 cm。共 326 朵。
2. **塔身**：调色板色块 cream (0.99,0.90,0.72)→(1.00,0.87,0.64)，cream2 (0.95,0.83,0.64)→(0.97,0.80,0.57)，更暖的奶油色。塔脚接地阴影：新节点 meadow_vb_tower_contact_shadow（半径 2.95–3.55 m 的两圈深绿环，贴地 3 cm，用调色板新色块 shade_1/shade_2）+ 地面贴图塔脚 AO 加强（0.34→0.44）。
3. **顶上那朵云**：它其实画在天空贴图 meadow_sky_4096x1024 里（不是 meadow_clouds_near 网格）。把旧云擦掉，重画成 10 个椭圆团组成的圆鼓云，底边也是圆团，顶白底灰蓝。贴图尺寸不变（4096×1024 JPEG q85）。对比：renders/top_cloud_sky_texture_before_after.jpg。
4. **蝴蝶**：身体和翅膀放大 1.5 倍（0.16→0.24 m，翅展 0.2→0.3 m）。meadow_butterfly_00 改走一条闭合样条：0–2.6 s 从左到右飞过游戏相机前方约 3.5 m（第 45 帧截图 renders/v7_1_frame045_butterfly_pass.png），然后飞回草地，8 s 循环首尾连续。另两只不变（只是放大）。
5. **鸟群**：路径改为 x −32→+58、y≈120、高≈48 m（比 v7 更近更低），约 3 s 进入画面，循环在画面外跳回。

## 已知弱点（诚实）
- 花瓣厚度在游戏相机距离下几乎看不出来，却让花网格大了约一倍；
- 塔脚接地阴影环大部分被围栏前的草挡住，游戏相机里只能看到一点；
- 新云比旧云略大一些，团块之间的分界在近看时有点像“气泡”；
- 飞过镜头的那只黄蝴蝶在最近时是低多边形平面翅膀，看起来像一张纸片；
- 预览用 CAM_spawn_pov，游戏里是 meadowScenePose，构图会有出入；
- 3 个新动画仍需 GGbot 在代码里显式播放（现代码默认关闭导入的 Animation）。
