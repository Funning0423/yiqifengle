# 草甸 v6 候选（Voice Bot，2026-10-15）— 只改云
**只是候选，未换进游戏，需 Funning 选定。** 输入 v5；只替换 meadow_clouds_near 网格（两簇），其余与 v5 字节一致（4 张贴图、其余所有网格、67 个节点、动画均脚本校验一致）。
## 做法
- 参考天空贴图里的云（renders/sky_texture_clouds_crop.jpg）：顶部几个圆鼓包向上拱起、底平、下部灰蓝阴影。
- 每簇 4 个低模椭球"鼓包"（10 段×5 环），中间两个最高、两边较小形成拱形，低于底面的顶点压平成平底；前后有体积（深度约为宽度的 0.8 倍半径），游戏相机下看不到"切片"厚度。两簇共 336 顶点、400 面。位置/尺寸沿用原球体簇的范围（scripts/cloud_boxes_orig.json）。
- 颜色：采样天空贴图云像素——亮部中位 sRGB (246,249,248)，阴影中位 (127,153,169)；顶点色按高度 smoothstep 渐变，底部为 80% 阴影色 + 20% 亮色的灰蓝，40% 高度以上为白。材质 M_meadow_cloud（unlit）不变，没有高光。
- 顶点色格式恢复为与原版相同的 float VEC3（COLOR_0，componentType 5126）。

## 诚实评价 / 已知弱点
- 竖屏游戏相机下，新云已是向上拱起的鼓包轮廓、平底、白顶灰底，比 v5 的"切片"好，也不再是光滑球；但比天空贴图的云**更硬、更几何**：鼓包边缘是明显的多边形折线，没有天空云那种柔和的小碎鼓包和模糊边缘。
- 近景（cmp_09）下每个鼓包的阴影渐变各自独立（按世界高度一致，但侧面较暗），看起来像几个低模球拼在一起；底部灰蓝比天空云略深。
- 若要更接近天空云，可下一步：每簇加 3–4 个小鼓包碎边（约 +150 顶点），或改为面向相机的 alpha 贴片（需要新贴图，超出本次约束）。
