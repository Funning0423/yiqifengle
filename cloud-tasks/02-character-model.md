# 任务 2：角色模型打磨（Opus 5.5）
现有交接：`art-src/character/HANDOFF.md`（分支 `work/角色建模bot`，带全部脚本、.blend、env.sh）。现状：body-r2 已通过的是小腿变细、裙摆上提；被退回要改的有：
1. **袖子**：现在肩膀是鼓起来的泡泡袖，前臂也鼓成气球。改成像 V12 那样宽松、顺直地垂下来，肩线平顺，只在袖口上方稍微堆一点褶，不贴手臂。
2. **手**：大小可以，但手指张开弯曲，像爪子。改成放松自然下垂，手指并拢、微弯，手背收圆。手离身体太远的问题，等围裙收窄后收回一半。
3. **鞋**：要高帮，但现在是方块状的重靴。改成细长的低跟短靴：鞋帮贴住脚踝，靴筒往上略收，鞋头圆而窄，加一道薄鞋底边，颜色偏 V12 的红棕。
4. **围裙**：收窄（现在比黄裙宽），加 V12 那条白腰带。
5. **头部**：以混元 3D 生成的头部（分支 `assets/hunyuan-head` 里的 `art-src/character/hunyuan/hunyuan_head_v31.glb`，150 万面）为底子，重新拓扑成游戏面数。头发要有明显体积和层次、蓬松，脸是圆下巴、大而亮的眼睛。五官不能只靠贴图，眼睛单独建模，要能眨眼。接到现有头部骨骼上。
**参考**：先上网查一下成熟的二次元低多边形角色做法（袖子布料走向、手的比例、短靴造型），按 V12 做。
**验收**：正面、侧面、四分之三侧、背面和 V12 并排的对比图；所有动画片段都过一遍穿模检查；glb 总大小 ≤ 1.5 MB。
