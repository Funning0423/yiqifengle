# RESULT：出门运镜节奏

分支 `cursor/exit-camera-pace-a0c7` → Pull Request 到 `int/v1`（草稿，未合并，没有推到 `int/v1`）。那一轮拿掉了摆镜的谷。

这一轮分支 `cursor/exit-crane-smooth-16df` → 草稿 PR 到 `int/v1`（未合并，没有推到 `int/v1`）。只把升镜的爬升改成平滑过渡。

产品第 6 轮：白天出门这一段（开门、跨门槛、沿路跟拍、摆到正面、升到海岛全景）走着走着会突然加快，没有平滑过渡。人没有停下来等镜头。

## 原因

出门是 `leaveHome` 里 opening-door 之后的一条 span：`outCrossing` + `toIsland` + crane settle（`cameraTracks.outbound`，pchip，easeIn 0.08，easeOut 0.2）。

两处速度接不上，都在这条 span 上：

1. **摆到正面。** `railOut` 五个姿势交给逐分量 pchip 时，转向那根轴的相邻斜率变号，切线被置 0。镜头线速度在仿真 13.4–14.4 s 从 **4.82 → 2.06 → 4.91 m/s**（朝向同时 **77 → 23 → 76 °/s**）。弦速度本来就在 3.6 m/s 左右，这个谷是插值造出来的，不是关键帧之间的距离和时间不成比例。
2. **升镜。** 等弧长步长只走到轨道一半，她停下之后剩下约 32 m 是 settle 上的**一段** Hermite。速度从约 3 m/s 爬到 **12.08 m/s**（19.8 s），再被 ease-out 收到 0。

另外试过把视野也放进同一条向心样条。位置弧长连续之后，铁路关键帧上视野曲率的台阶被走得太快，视野速率在 13.78 s 附近一帧从约 −14 °/s 收到 −9 °/s（**dfv ≈ 230 °/s²**，修前全程最大是 84）。视野改回沿 span 进度的标量 pchip，关键帧上的 fov 不变。

## 改了什么

只动出门这一段的镜头节奏。

- `FirstsliceRoutes.paceOutbound`：向心 Catmull-Rom 穿过原来的 span 关键帧（跨出门、`railOut`、等 u 的 crane 步、`cameraIsland`）。摆镜之前用弧长对进度的标量 pchip 取样，每个关键帧仍落在原来的走路进度上（正面 0.43、crane `startProgress` 0.553、风的键不动）。crane 起点之后，跟拍速度用 smoothstep 铺到出门 ease-out 开始的那一刻（大约 3.64 s），两端加速度是 0，再交给原来的 ease-out 收到静止。不再用 1.2 s 的短斜坡接到 9.11 m/s 的平段。视野是关键帧 fov 对 span 进度的标量 pchip，不再走那条向心样条。
- `WorldFlowCore.leaveHome`：有 `cameraSettle` 时，升镜关键帧记在 settle 时钟上（最后一帧仍是 `cameraIsland`），`cameraToIsland` 停在她停下那一刻的姿势，不再把整段升镜收成一个 Hermite 段。这一轮没有再改 `leaveHome`。
- `RegionCameraData.crane.pace`：`sampleMetres: 0.15`。`craneRampSeconds: 1.2` 已去掉。`startProgress`、`settleSeconds`、`steps`、`railOut`、`windOut`、门的角度都没改。

没有改回家、风的含义（出门变大，摆到正面时为 1）、门的开合、角色、`CharacterMotion.ts`、角色 GLB、裙子、门的网格、道具、棋盘。

她的走路时长没变（`outCrossing` 2.839 s，`toIsland` 6.263 s，settle 2.992 s）。镜头进度仍跟距离走，人不等镜头。

## 升镜

int/v1（`34fd323`）已经拿掉摆镜那个谷，也把 settle 上一段 Hermite 的 **12.08 m/s** 收成巡航。玩家还是觉得会突然加快。剩下的加速在升镜起步：跟拍约 **3.17 m/s**，用 **1.2 s** 的 smoothstep 爬到 **9.11 m/s**（15.6–16.8 s），加速度到 **7.45 m/s²**，然后平着走到 ease-out。

这一轮把爬升铺到出门轨道 ease-out 开始（crane 起点 15.567 s → 约 19.20 s，大约 3.64 s）。smoothstep 两端加速度是 0，ease-out 在接头的加速度也是 0，速度顶过去再收到静止，中间没有平段，也没有再冲一下。摆镜 13.4–14.4 s 仍是 4.04–4.24 m/s。`WorldFlowCore.leaveHome` 的 settle 切分没再改。

升镜弧长约 44.3 m，从 crane 起点到停稳大约 6.06 s，平均约 7.3 m/s。跟拍盖不满这段路，速度一定会升。拉长之后，60 fps 最大线速度是 **11.23 m/s**（19.2 s），仍低于原来那一段 Hermite 的 12.08。爬升段最大加速度约 3.33 m/s²（17.4 s）。
