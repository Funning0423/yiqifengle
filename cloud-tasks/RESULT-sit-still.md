# RESULT：坐稳以后保持 sit_hold 第 0 秒

分支 `cursor/sit-still-268b` → PR 到 `cursor/sit-drape-0dfd`（草稿，未合并，没有 push 到 int/v1）。起点是已经推上去的 `cursor/sit-drape-0dfd`。

## 结论

坐下之后不再晃。`sit_hold` 整段 2 秒都是第 0 秒那一帧：髋、脊柱、胸、头、手、裙骨都停在坐稳姿态上。形状键没改。走路、开门、转身、坐下、站起的姿势数据和改之前逐帧相同。

| 验收项 | 结果 |
|---|---|
| 坐稳后不再晃髋 | 改之前髋骨相对第 0 秒最大 **28.0°**（1.25 s；0.5–1.5 s 是 25–28°）。改之后每个采样都是 **0.00°** |
| 裙子不再跟着循环晃 | 裙骨停在坐稳帧。黄裙-椅子在 0.5 / 1.0 / 1.5 s 从 12 / 11 / 16 对变成 **0**；围裙-黄裙从 6 / 6 / 0 变成 **0** |
| 呼吸、头发 | 这套运行时 glb 没有单独的头发骨（头发在头网格上）。头的局部旋转原来最多 33°，胸 9.1°、脊柱 8.7°，都停在第 0 秒。改之后侧面、正面、四分之三的 8 张图逐像素相同 |
| 坐稳帧的裙骨和 sit_drape | 没重做。黄裙 `sit_drape` 仍是 **17,220 B**，围裙 **3,948 B**，占位目标各 14 B。字节和改之前一致 |
| 手掌抬高约 1.5 cm | **没改。** 抬 15–40 mm 都不能让手掌压在围裙上面，见「手」 |
| 运行时 glb ≤ 1.5 MB | 1,374,704 → **1,373,744 B** |
| 关键帧 | `art-src/animation/sit-still/previews/keyframes_sit_hold_2s.jpg` |

## 改了什么

只动 `sit_hold` 这一个片段里已经有的旋转 / 平移通道。每条通道改成 t=0 和 t=2.0 两个相同的 LINEAR 关键帧，值是原来第 0 秒的局部姿态。40 条通道、80 个关键帧。没有加骨头，节点名、层级、28 个 skin joint、材质和贴图都没变。`.glb.meta` 没改（片段时长仍是 2.0 s）。

第 0 秒的 10 根裙骨就是上一轮垂坠写进去的坐稳帧，原样留着，只是不再在 0.25–1.75 s 跟着髋部重摆。`sit_drape` 权重曲线仍是 `[[0,1],[2,1]]`。

`sit_down`、`stand_up`、走路、停步、转身、`door_reach`、`idle_breathing_loop`、`wind_sway_loop` 在 30 fps 上和改之前的局部旋转、平移差是 0。

`anim_meta.json` 里 `sit_hold.keys` 改成「停在第 0 帧」，`source.hold` 记了一句。形状键曲线、`settle_time_s`、`morph.meshes` 没动。

## 穿模

运行时 glb 导入 Blender，按驱动摆（片段姿势 + 根节点位移 + `sit_drape` 权重），BVH 三角形求交。改之前的数是 `art-src/animation/sit-drape/qa/verify_after.json`，改之后是 `art-src/animation/sit-still/qa/verify_hold.json`。下表只列有变化的格子，格式为改前 → **改后**。没写的格子两边相同。

| 帧 | 围裙-黄裙 | 黄裙-椅子 | 蝴蝶结-椅子 | 手-围裙 L / R |
|---|---|---|---|---|
| sit_hold 0（坐稳） | 0 | 0 | 32 | 135 / 215 |
| sit_hold 0.5 | 6 → **0** | 12 → **0** | 32 | 0 → **135** / 0 → **215** |
| sit_hold 1.0 | 6 → **0** | 11 → **0** | 34 → **32** | 0 → **135** / 16 → **215** |

腿-黄裙、腿-围裙、腿-椅子、躯干-椅子、黄裙-地面在这四帧都是 0。手-围裙在晃的时候有的帧碰巧是 0，停住以后一直是坐稳帧的 135 / 215，和「手没动」一致。

`sit_down`、`stand_up` 抽查的每一帧（0.2 到 1.2 s、0.13 到 1.0 s）穿插对数和改之前逐项相同。过渡帧该穿的还是穿，这一轮不动它们。

## 手

坐稳帧手掌仍然陷在围裙里：手-围裙 135 / 215 对。上一轮记的最深约 18 mm。这一轮试过只抬坐稳姿态的手，不改形状键、不改裙骨：两段 IK 把手腕沿世界向上抬 15、18、20、30、40 mm，手掌朝向不变。黄裙、围裙、蝴蝶结的蒙皮权重里没有手臂，抬手时这三块网格的顶点位移是 0，腿-黄裙、腿-围裙保持 0，没有反弹。

手掌没有因此压到围裙上面。抬 15 mm 时手-围裙仍是 144 / 132 对，左袖-围裙从 35 对增到 64 对。抬到 40 mm 还剩 147 / 78 对。手是嵌在围裙那一层里面，不是在布下面差 1.5 cm，所以只抬手腕出不来。按「抬约 1.5 cm 就能压在围裙上才改」这一条，手保持原样。

## 遗留

1. **手掌陷进围裙**：坐稳帧 135 / 215 对。只抬手解决不了，见上。要手掌压在布上，得改围裙在手掌处的形状，上一轮那样做会把腿-黄裙穿插拉回来。
2. **蝴蝶结尾巴穿座面**：坐稳帧仍是 32 对。晃的时候曾经到 34 对，停在第 0 秒以后回到 32。正面看不到，这一轮没改蝴蝶结。
3. **坐下和站起的过渡帧**还是上一轮那些穿插（腿-黄裙大约 400，黄裙-椅子最多 500 多）。`sit_down` / `stand_up` 没改。
4. **头发**：运行时 glb 的 skin 是 28 根身体骨，没有头发骨。头网格上的头发跟着头骨，头已经停住。
5. **室内没有风的时候** `wind_flutter_loop` 权重是 0，不会在坐着时再把裙子叠上去。室外的风效层没动。
