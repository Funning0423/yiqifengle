# 任务 3：坐姿裙子垂坠（Opus 5.5，任务 1、2 完成后做）
**问题**：每片裙片只有两段骨，第一段在大腿中间就结束了，弯不到膝盖。所以坐下时裙子要么穿过椅子和腿，要么撑得像帐篷。
**产品决定**：给黄裙和围裙各做一个「坐姿垂坠」形状键，不加骨头。坐下时权重从 0 过渡到 1，权重曲线写进 anim_meta，做法和现有的围裙卷边形状键一样。驱动现在只给 `LOD0_G2_APRON` 设形状键权重，要加上对黄裙的支持（代码在 `creator-build-project/assets/scripts/CharacterMotion.ts` 和 `WorldIntegrationBoot.ts`）。用房间里真实的椅子尺寸来做。
**验收**：坐稳那一帧不穿椅子、不穿腿，黄裙和围裙之间不互相穿；anim_meta 写上 settle_time_s；每个形状键 ≤ 20 KB。交付坐稳那一帧的截图，用来重渲加载页的底图。
