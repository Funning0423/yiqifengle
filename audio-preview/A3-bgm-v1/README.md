# A3 BGM v1（Voice bot 原创，程序合成）

- 风格：温暖、轻风、惊叹，无战斗感。F 大调，92 BPM，32 小节，83.5 秒。
- 编制：柔和铺底和弦、拨弦琶音、卡林巴主旋律（第三段换成铃音加卡林巴）、低音、很轻的沙锤和底鼓、每 8 小节一阵风声（呼应“起风了”）。
- 无缝循环：尾音和混响在合成时折回到开头（循环卷积），首尾样本连续。MP3 编码本身首尾填充可能带来极短空隙，需真机确认；不行再改 AAC 或代码里交叉衔接。
- 文件：bgm_main_v1.mp3，96 kbps 立体声 44.1 kHz，1.0 MB，约 -16 LUFS（旧 BGM 约 -29 dB 平均，太轻）。
- 试听：bgm-v1-preview-loop.m4a 连放约 1.2 遍，第 83.5 秒处是循环接缝。
- 版权：全部由 bgm.py 程序合成，无采样、无外部素材。
- 仍放在 audio-preview，未替换 resources/audio_bgm/bgm_main.mp3。
