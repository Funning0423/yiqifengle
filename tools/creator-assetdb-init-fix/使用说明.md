# Creator 3.8.8 Meta 修复补丁

用于修复 macOS Cocos Creator 3.8.8 自动打包时，因 AssetDB 初始化竞态漏注册导入器，导致正常 `.meta` 被改成 `ver: "0.0.1"`、`importer: "*"` 的问题。

## 包内文件

- `cocos-assetdb-init-bridge.cjs`：核心补丁，在 AssetDB 初始化完成后补齐已启用扩展中漏注册的导入器。
- `fix-cocos-assetdb-init.py`：安装与回滚脚本，使用 Python 3 标准库，无需安装额外依赖。
- `使用说明.md`：本说明。

请将这三个文件保留在同一目录。

## 安装

1. 退出要修复的 Creator 实例。
2. 在终端进入本补丁解压后的目录。
3. 执行以下命令；如 Creator 安装位置不同，请替换为实际路径。

```bash
python3 fix-cocos-assetdb-init.py /Applications/Cocos/Creator/3.8.8/CocosCreator.app
```

输出 `installed` 表示安装成功；`already-installed` 表示该安装包已安装补丁。

补丁修改 Creator 安装包内的 `app.asar`，只需安装一次，无需每次打包执行。脚本会校验已验证的官方 3.8.8 安装包及 AssetDB 文件哈希；不匹配时会拒绝修改。

安装成功后会生成回滚记录：

```text
CocosCreator.app/Contents/Resources/app.asar.assetdb-init-fix.json
```

请保留该文件。重装或升级 Creator 后，需要重新核验；脚本不会将补丁应用到未知版本。

## 回滚

退出目标 Creator，在补丁目录执行：

```bash
python3 fix-cocos-assetdb-init.py /Applications/Cocos/Creator/3.8.8/CocosCreator.app --restore
```

输出 `restored` 表示已恢复修复前的安装包字节。如果安装包在打补丁后被其他操作修改，脚本会拒绝覆盖。
