## 1. 氛围与光
夏·午后雷阵雨刚停：空气被洗过，色彩饱和、对比强。太阳从**右上后方**斜照，积云之间留缝，云影成片落在江面和峰林上（光有来源、有遮挡）；远处一道淡彩虹作情绪点。**不铺整片雾**：只在最远一层峰林脚下留一条薄水汽带（<画面高度 8%），上三分之一保持天空 + 云 + 峰顶剪影清楚。

## 3. 名胜参考（只取元素，外形原创）
- **桂林漓江 / 阳朔一带**：取"江面两岸圆柱状喀斯特峰林、层层空气透视、竹筏、鸬鹚、水牛"的**地貌与生活意象**。峰林由噪声扰动的圆润体块原创生成，不对照任何具体山峰（如人民币背面图景、象鼻山等标志轮廓一律不做）。
- 渔家吊脚木屋为原创比例的通用民居，不复刻任何景区建筑。
- 游戏内地名用原创名：「青螺江」「九叠峰」。

## 4. 棋盘融合方案：「一张大竹筏」（区别于湖畔浮标）
- **棋盘本身就是一张漂在江上的 7×7 大竹排**：每一格是一截锯开的竹筒（三根细竹并排 + 节环），格与格之间麻绳绑扎；两侧有粗浮竹。不是发光面板，格子边界靠竹节和绳结读出来。
- **整张筏一起漂**：棋盘随水流做极慢的整体纵摇/横摇（±1.5°，2.5 s 周期），棋子不各自浮动，而是**跟着筏一起倾斜、在竹筒槽里轻滑半格后回位**——"一个整体在水上"的手感。
- **拖动 = 竹筒倒水**：拖起棋子时竹筒口溢出一小股水，落下时筒口溅出水珠并在筏边扩出涟漪圈（复用湖畔水花粒子，换成竹节音效"咚"）。
- **新机制「水流格」**（SCENE-ROADMAP）：江水从上游流过，指定一行竹筒每 3 步整体顺流左移一格——视觉上是那一排竹子被水推着滑动、绳子拉紧，读得懂。
- **连消反馈**：≥4 连消时，筏头的鸬鹚扑翅入水叼回一条小鱼；通关时筏沿着江漂向下一个弯（衔接转场到秋林小站）。
- **边框**：竹排外圈绑麻绳 + 两侧浮竹；四角立小竹竿挂斗笠（剩余步数提醒：斗笠逐个被风吹落）。
- **彩蛋**：雨后彩虹倒影（1/20，点中收入风物志）；水牛在浅滩甩尾溅起水花打在棋盘上，随机给一格"洗干净"。
- **棋子（6 类，放大 1.45×，按形状+颜色双编码）**：西瓜片（红/绿半圆）、莲蓬（黄绿圆盘多孔）、斗笠（金色圆锥帽）、鹅卵石（青灰椭圆）、竹蜻蜓/蜻蜓（橙身透明翅）、荷花徽章（粉色花瓣）。

## 5. 构图与安全区

## 8. v8 修订（按 Grok Bot 意见）
- 峰林：石灰岩圆顶陡壁峰，岩面灰 + 岩纹横带 + 顶部/坡面灌木，高低胖瘦随机；前中远三层，层间各一条半透明低雾带（不铺满）。
- 江水：深槽 + 两岸浅滩三色，顺流白沫短纹，峰林/天空倒影；右侧低角度强侧光（夏日午后），按太阳方向在光路上放积云，云影落在江面上。
- 两岸：左岸吊脚屋 + 渡口栈桥 + 灯笼桩 + 系着的小竹排 + 竹林；右岸水车 + 竹槽引水 + 浅滩水牛 + 竹林。
- 棋盘：竹排直边 + 竹节 + 横向木条 + 麻绳绑扎，已去掉白色椭圆圈；7×7，棋子同尺寸居中对格。
- 人物：阿芳戴斗笠、蓝衣红围巾，撑竹篙站在棋盘右上角的小竹排上。

## 9. v9 修订（2026-10-16，内部迭代 v9→v11，交付取 v11 记为第 9 版）
- 峰林：改为原创塔状峰——近垂直棱纹崖壁、腰部微收、顶部小冠，倾斜/宽窄随机；崖面嵌纵向凹陷岩洞，崖壁挂灌木丛，冠顶植被。不再用椭球（去软糖/蛋形）。
- 雾带：多层低透明度（5–11%）叠壳 + 随机缺口，边缘渐隐、断续，不再是硬边横带。
- 棋子：伪随机洗牌（种子 2026），每种 8–9 个（西瓜 9、其余各 8），无三连；西瓜红降饱和 #E0646A，莲蓬改黄绿 #C8D04A，石子/蜻蜓/荷花同步降饱和，6 种明度饱和度更平衡。
- 江水：删除白色短线；改为顺流的长条低透明柔波（3.5%）。水色加深（#06475E / #0C7480），低粗糙度 + 顺流拉伸噪声凹凸；右上受光区暖金柔光反射（scripts/sheen.py 柔边叠加，对应 Cocos 水面高光）+ 细碎闪光片 170 个；云影区仍由光路积云投射。无光柱/光束。
- 近景：去掉底部深青硬色块，江面延伸到镜头前；加水草、浮叶、三只游来的鸭子（带涟漪）、渔网浮标线。底部 ≥18% 为安全区，无可交互物件。
- 保持：两岸布局、阿芳造型不变。场景实测 55,054 三角面 / 1,267 物体（log_v11.txt）。
- 文件：v8 备份 `renders/bamboo_concept_v8_720x1280.png`；对比 `renders/bamboo_v8_vs_v9.png`；v8 脚本备份 `scripts/concept_v8.py`。

## 导出规则（2026-10-17，所有场景通用）
竹筏目前只有概念图，还没有导出 GLB / transforms。以后导出一律用通用脚本 `art/tools/export_region.py`，导出后用 `art/tools/check_region_export.py` 自动检查，不要再写各场景自己的导出脚本。原因：湖畔 r5h3 的旧导出脚本把隐藏的 ASSETS 模板集合也写进了场景实例，34 个模板堆在原点，导致桥上多出亭子、湖面和地形重叠闪烁。通用脚本只导出最终渲染里看得见的实例；模板网格仍各自导出为 GLB 资产，但不会作为实例出现在场景里。
```
blender -b blend/bamboo_xxx.blend --python ../../tools/export_region.py -- \
  --models ../models --out ../scene_bamboo_transforms.json --meta ../scene_bamboo_export_meta.json \
  --template-collections ASSETS --board-collections <棋盘集合> --exclude-glb <不进包的GLB> --camera <棋盘相机>
python3 art/tools/check_region_export.py art/regions/bamboo-raft/scene_bamboo_transforms.json art/regions/bamboo-raft/models --unique <只应出现一次的GLB>
```
