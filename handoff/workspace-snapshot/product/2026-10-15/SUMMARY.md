# 《咦 起风了》设计一页摘要（2026-10-15 · Owner：Funning）

**定位**：一款安静、温柔的“边走边消除”旅程小游戏（Cocos Creator 3.8.8，low-poly 3D）。阿芳推开小屋的门追着风走过 8 个地区，每个地区拿到一件线索，最后在山丘上和阿宁重逢。完整文档：`DESIGN.md`。

**市场结论**（来源见 DESIGN §1、§8.3）
- 2025 年微信小游戏 DAU 超 1 亿、MAU 5 亿；休闲用户兴趣集中在消除和解谜，平台看好“画面精美 + 社交趣味”的女性向休闲游戏（游戏葡萄 / 2026 微信公开课）。
- 要学的：Gardenscapes 的“过关 → 世界变化 → 故事”；Royal Match 的大号、有体积的棋子和会做反应的角色；合成大西瓜每次消除都有反馈；Neko Atsume/Alba 的无压力图鉴；Monument Valley 的“白盒 → 可读 → 精修”和“结局很重要”。
- 不学的：羊了个羊的地狱难度和反复看广告、体力系统、断签惩罚。
- 变现：免费；激励视频可选且默认关闭（流量主要满足条件才能开，例如 UV > 500），**任何设计都不依赖广告**。

**P0 待办**：包体从约 28.1 MiB 压到 ≤ 24 MiB 并按地区分包 · 原创加载页（去掉剧照）· 海岛活的棋盘 · 岛上每关通关走几步 + 小帆船去草甸 · 线索系统 · 回家运镜 · 宝箱居中验收。

**故事**：做风筝的阿宁三年前离岛，说“等我做出能载两个人的风筝就飞回来接你”，后来信断了。线索：纸飞机（半句话）→ 信 → 黄围巾 → 刻名风铃 → 单程车票（不安）→ 观风日志 → 断风筝翼（最低谷）→ 另一半纸。结局：“我本来明天就要去接你的。”“我先来了。”纸飞机原来是他放出的试飞，两人乘风筝飞回家，小屋多了一把椅子。只借电影的氛围，不用其中任何角色、名字、情节或画面。

**8 个地区 / 47 关**：R1 海岛灯塔（主01 + 9 海岸关）· R2 风车草甸（5）· R3 天空之城（6）· R4 风铃湖畔村（6，风铃格）· R5 秋林铁路（6，小火车轨道 + 落叶）· R6 雪夜观星台（6，冰封 + 星图）· R7 云海（5，风向重力 + 云遮）· R8 山丘重逢（3，放风筝线；最后一关降难）。新区每区 ≤ 1.0 MiB 分包，顶点色 + 共享调色板 + instancing。

**转场**：海岛→草甸选**小帆船**（世界逻辑通顺、帆鼓起点题“起风了”、复用海面 shader、成本低；彩虹桥 overdraw 大，步行违背隔海关系）。另有缆车、滑翔风筝、步行、小火车、老铆托举、步行登山、结局飞行（约 40 秒），以及纸飞机回家（约 9 秒）；每段都有分镜和时长；第二次起可跳过。

**活的棋盘**（DESIGN §5）：每区有 (a) 场景材质的边框和格子（浮木、栅栏、白石铜条、栈道风铃、铁轨信号灯、雪框冰凌、云台、风筝线草坡），且在安全区内边界清楚；(b) 6 种有体积的主题棋子（烘焙精灵、同一张图集）；(c) 真实 3D 场景实时作背景（海浪、草浪、风车随连消加速、云流即风向、昼夜）；(d) 棋盘边上的小动物：海鸥、螃蟹、羊、猫、风铃、鸭、松鼠、猫头鹰、雪人、飞鱼、纸鹤，各有点击、连消和通关反应，还有稀有彩蛋（漂流瓶、黑羊、流星、云鲸……），并收进**风物志**图鉴（剪影提示、保底概率、只给装饰奖励）。
**性能预算（高档/低档）**：Draw Call ≤ 70 / ≤ 40；三角面 ≤ 70k / ≤ 20k；同时在动的小动物 ≤ 3 / ≤ 1；无实时阴影、无后处理；分三档自动降级。

**验收**：安全区与胶囊按钮、图标大于文字、宝箱居中且醒目、3D 体积（按钮三态、接触阴影）、色板与光照一致、版权轮廓检查、20 分钟真机性能。

**路线图**：M0 瘦身（10-16–10-19）→ M1 海岛成型（–10-26）→ M2 草甸与天空之城（–11-09）→ M3 湖畔与铁路（–11-30）→ M4 观星台、云海、终章（–12-21）→ M5 发布候选（–2027-01-04）。grokbot-2 美术与验收 · GGbot 代码与构建 · Voice Bot 音频 + 风车/小路 · 运镜bot 转场 · Oi 角色与云端测试 · 界面验收部 UI 验收 · 场景设计（新区域，**需指派**）。
