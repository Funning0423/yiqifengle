# 玩法融合方案集（草稿，图待渲染）
7×7 交换消除，棋盘统一 7×7、每格 1 单位；5 个方向都不是"水面漂浮"。每个方向一张 720×1280 概念图，总览见 overview.jpg。

## A 秋林铁路 · 货箱车厢（A_rail_crates.png）
- 场景：秋日下午，红叶林边停着一节平板货车，前方是小火车头和信号灯，地上铺满落叶。
- 棋盘载体：车厢上码着 7×7 只开口木货箱，深浅相间，一箱一格；车轮和铁轨从棋盘下穿过，正好接上"小火车轨道"机制。
- 道具与消除：枫叶、橡果、蘑菇、松果、栗子、车票；消除时道具从箱里旋转飞出，卷起一阵落叶小旋风，空箱再"咚"地补货。
- 可玩性：格宽约 90–100 px（720 宽），点击区 = 整个箱口；俯角 58°，远排也看得清。

## B 雪夜观星台 · 星图桌（B_snow_starmap.png）
- 场景：雪夜山顶木平台，背后是圆顶观星台和大望远镜，雪松、淡淡的极光和满天星。
- 棋盘载体：一张深蓝玻璃面的木星图桌，金色细线刻出 7×7 格，桌角压着圆圆的积雪。
- 道具与消除：星星、雪花晶、热可可、手套、松枝、望远镜徽章；消除的星星升上夜空，用金线连成一段星座（呼应"星图"机制）。
- 可玩性：深底亮子对比最强，格宽约 90–100 px；金线只当格界，不抢道具。

## C 云海 · 崖顶石台（C_cloud_terrace.png）
- 场景：黎明，黄山式奇松长在崖顶，脚下是粉金色云海和远处石柱。
- 棋盘载体：崖顶天然石台铺着 7×7 块圆角石板，石缝长苔，像古人留下的棋局。
- 道具与消除：云朵、曦光石、纸鹤、羽毛、风哨、风筝徽章；消除时道具"噗"地散成一团小云飘走，偶尔飞起一只纸鹤。
- 可玩性：浅暖石板配深色苔缝，格界清楚；格宽约 90–100 px。

## D 山丘重逢 · 野餐布（D_hill_picnic.png）
- 场景：初夏夕阳下的草坡顶，远处薰衣草田一条条铺开，几只热气球剪影，一个圆圆的夕阳。
- 棋盘载体：一块奶白×薰衣草紫的格纹野餐布，天然就是 7×7 格，布角是圆的，旁边放着藤篮和风筝。
- 道具与消除：萤火虫瓶、蒲公英、风筝、信封、围巾结、半张纸；消除时蒲公英种子和萤火虫一起飘向夕阳。
- 可玩性：格纹本身就是格子，最直观；俯角 50°，格宽约 90–100 px。

## E 备选 · 秋林小站信格柜（E_station_mailwall.png）
- 场景：秋林小站候车室，窗外是红叶和停靠的小火车，暖灯下落叶从门口吹进来。
- 棋盘载体：墙上一只 7×7 木质信格柜，正面平视，每个小格是一个格子。
- 道具与消除：枫叶、信件、车票、橡果、蘑菇、松果；消除时道具变成信封从格里滑出飞走。
- 可玩性：正视无透视变形，格子完全等大最好点；代价是看不到地面纵深，场景主要靠窗外。

## 通用交互
按下/拖动：暖白细光圈 + 轻抬；消除：放大到 1.18× 约 0.12 s 后接各场景专属特效。
