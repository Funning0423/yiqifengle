# 玩法融合方案集 v2（7×7 交换消除）

v1 已移到 `_v1/`。v2 的五个方向都不是"水面漂浮"。为了让格子在竖屏上接近正方形、宽高都 ≥ 90 px，棋盘载体要么是立着的，要么是斜面，镜头基本正对棋盘；画面上方约 1/3 到 2/5 留给场景地标。每格都放了该场景的道具；画面里有一个格子带暖白选中光圈，还有一行三个道具放大到 1.18 倍，用来示意消除特效。
脚本：`scripts/gic2.py`（Blender 5.2 EEVEE，原创低多边形形状，不用贴图）。后期：`scripts/post2.py`（饱和度 ×1.22，对比度 ×1.06，轻暗角）。格子像素实测汇总在 `scripts/qa_summary.txt`。

## A 秋林铁路 · 货箱车厢（A_rail_crates.png）
- **场景：** 秋日下午，红叶林谷地，远处石拱高架桥上开过一列小火车，背后是雪山，路边立着信号灯。
- **棋盘载体：** 平板车厢侧面码着 7×7 只木货箱，箱口朝外，一箱一格；车轮和铁轨就在棋盘下方。
- **道具与消除：** 枫叶、橡果、蘑菇、松果、栗子、车票；消除时道具从箱口旋出，卷起一阵落叶小旋风，空箱再补货。
- **可玩性：** 正视的立面棋盘，格子 91–93 px 见方，点击区 = 整个箱口。

## B 雪夜观星台 · 星图架（B_snow_starmap.png）
- **场景：** 雪夜山顶的木平台，岩丘上是圆顶观星台和伸出的望远镜，旁边有亮着暖灯的小木屋，还有雪松、远山、淡淡的极光和星空。
- **棋盘载体：** 一张斜立 67° 的木框星图架，深蓝玻璃面上用金色细线刻出 7×7 格，四角压着圆圆的积雪。
- **道具与消除：** 星星、月牙、彗星、行星、望远镜、观风日志；消除的星星升上夜空，用金线连成一段星座。
- **可玩性：** 深底配亮色道具，对比最强；格子 91–98 px 宽 × 91–101 px 高（远排 93×91，近排 98×101）。

## C 云海 · 崖顶斜石台（C_cloud_terrace.png）
- **场景：** 黎明时的黄山式奇松崖顶，脚下是粉金色云海，远处石柱上也长着松，一只断了线的红风筝挂在松枝上。
- **棋盘载体：** 一块 45° 斜立的天然岩台，上面铺着 7×7 块圆角石板，石缝长苔。
- **道具与消除：** 云朵、曦光石、纸鹤、羽毛、风哨、松枝；消除时道具"噗"地散成一团小云飘走，偶尔飞起一只纸鹤。
- **可玩性：** 格子 94–100 px 宽 × 91–103 px 高（近排稍大）。

## D 山丘重逢 · 坡顶野餐布（D_hill_picnic.png）
- **场景：** 初夏夕阳下的草坡，坡顶有大树和两人座秋千；坡后是薰衣草条田，几只热气球飘在谷里，还有一只红风筝。
- **棋盘载体：** 铺在 36° 草坡上的格纹野餐布（奶白 × 薰衣草紫），布格本身就是 7×7 棋盘；布格是长方形，正好抵消透视，让屏幕上的格子接近正方形。
- **道具与消除：** 萤火虫瓶、风筝、信封、围巾结、草莓、蒲公英；消除时蒲公英种子和萤火虫一起飘向夕阳。
- **可玩性：** 格纹天然就是格子，最直观；格子 92–100 px 宽 × 88–104 px 高（最远一排高 88 px，略低于 90，后续可把布格再拉长 3%）。

## E 备选（云海 / 终章）· 云海上空的大风筝（E_sky_kite.png）
- **场景：** 云海上空，石柱上的阿芳（黄围巾）拉着风筝线，远处有一道淡紫色的云鲸影和一群纸鹤。
- **棋盘载体：** 一只八角大风筝，竹骨把风筝面分成 7×7 格，正面对着镜头，下面拖着彩带尾巴。
- **道具与消除：** 纸飞机、蝴蝶结彩带、铃铛、飞鱼、气球、风筝徽章；消除时道具化成彩带，顺着风筝尾巴飘走。
- **可玩性：** 正视的立面棋盘，格子 91 px 见方。

## 通用交互
按下或拖动时出暖白细光圈，道具轻轻抬起；消除时放大到 1.18 倍，约 0.12 s 后接各方向自己的特效（落叶旋风 / 星座连线 / 散成小云 / 种子和萤火虫飘走 / 彩带飘走），五个方向互不重复。
