# 玩法融合 v4 思考稿：棋盘是那个地方本来就有的东西
> 场景设计部｜2026-10-17｜只是思路，没有出图，也没开 Blender。依据：DESIGN §3.2 / §5、SCENE-ROADMAP、v3 五张图与 Funning 的原话。

## 0. 先算一笔几何账（这决定了"包住"怎么做）
7 列 × ≥ 88 px 至少要 616 px，720 宽的画面里左右各只剩约 50 px；按 v3 实际的 7 列 × 91 px = 637 px 算，左右各只剩约 40 px，棋盘下沿在 7% 处（约 90 px），上沿在 57% 处。所以**左右两侧不可能"摆满东西"**，"包住"只能靠两点：
1. 载体所在的那块地面（或那个物体）**本身一直延伸到画面外**，棋盘只是它的一部分；
2. 少量场景元素**跨过**格子边缘（每处 ≤ 1/3 格，不盖住棋子中心 60%）。
另外，v4 把棋盘下沿从 7% 抬到 **10%（约 128 px）**，给底部前景留出位置；上沿约到 60%，上方仍有约 40% 给地标。

## 1. D 为什么成立 → 6 条可检查的规则
野餐布本来就会铺在草坡上；草从布的四周，包括下方，一直延伸到画面外；格子就是布上自己的格纹；棋子是野餐时会带的东西。遮掉棋子以后，画面就是"夕阳草坡上铺着一块空野餐布"，是一张完整的画。v3 的 A/B/C/E 都是"带粗边框的托盘 + 背后一张画"：A 是红边平板车，火车像贴在后面；B 是蓝底金线桌；C 是一块方石板；E 的风筝是竖着的面板。遮掉棋子以后，剩下的是一个空托盘。

| # | 规则 | 怎么检查 |
|---|---|---|
| R1 本来就在 | 不提"游戏"，这个东西也会出现在这里 | 能用一句话说出它在故事里为什么在这儿 |
| R2 地面连续 | 载体下面或周围的那块地面，至少 3 条边延伸出画面 | 沿棋盘四边各走一步，踩到的是同一片地 |
| R3 格子是自己的纹理 | 分格来自载体本身的接缝、格纹、田埂或板缝，没有另画的框和金线 | 去掉棋子，格子仍是这个物件的样子 |
| R4 前景压边 | 底部 ≥ 100 px 有前景，至少 2 处跨过棋盘边；两侧各有 1–2 处跨边 | 跨边只盖格子外缘，不盖棋子中心 |
| R5 同一套光 | 棋盘和场景共用太阳光、接触阴影与色温；**大块投影不落进格子** | D 现在的树影压了右上 3×3，这一点 D_refine 要修 |
| R6 遮棋测试 | 遮掉棋子后还是一张风景画 | 每张图都另出一张"遮棋版"交验收 |

另外每张都要满足：消除效果会跑出棋盘、进入场景（风、小动物、地标有反应）；红线照旧，不加雾、不加光柱、不发白，格子 ≥ 88 px、接近正方形。

## 2. 四个方向逐个改

### A 秋林铁路 → 换载体：林中小站的石板月台
- **载体**：小站月台铺着方石板，7×7 格就是石板缝分出来的；石缝里卡着落叶和青苔，石板有深浅两色，天然就是奇偶格。不再用货箱和平板车。
- **四周**：上方是小站木屋的檐角、站牌和挂钟，再远是红黄彩林和弯过来的石拱高架桥（地标）。左边一条铁轨紧贴月台边，伸出画面，枕木跨过左沿；小火车从左上驶进站，正好把 DESIGN 的"小火车轨道"机制放到了真轨道上。右边是长椅（放阿宁的围巾线头彩蛋）和枫树干，月台继续延伸出画面。
- **底部前景**：一根近景枫枝和一盏站台灯柱底座压住右下角；一只旅行箱的角压住左下角。
- **棋子与容器**：棋子是落在石板上的秋物：枫叶、橡果、栗子、松果、蘑菇（长在石缝苔里）和车票。每格中间有一层薄落叶垫，像落叶自己堆出的窝。
- **消除**：一阵风把棋子卷起，顺着铁轨方向吹进林子；连消 ≥ 4 时火车鸣笛，松鼠从长椅上探头接住橡果。
- **遮棋后**：一座铺满落叶的秋日小站月台。✔
- **可玩性**：石板网格天然规整，7×7 很自然；格子 91 px 没问题。风险是暖色叶子和暖色石板撞色，所以石板压成灰褐、低饱和，棋子保持高饱和并加暗描边。
- **性能**：石板 49 块，每块 12 面，instanced；站屋 ≤ 2k，树 instanced，背景约 35k，能做到 ≤ 45k、≤ 1.0 MiB。

### B 雪夜观星台 → 换载体：观星台前的积雪木格露台
- **载体**：观星台前的木露台，铺的是方形拼木地板，相邻两块的木纹方向一横一竖，本身就是棋盘格；板缝里积着细雪。不再用斜放的星图桌。
- **四周**：上方是缩小后表面光滑的圆顶观星台、斜指星空的大望远镜和极光，星空占画面上方约 30%。左边是挂冰凌的栏杆，两根栏杆柱跨过左沿，雪松枝从画面外伸进来。右边是小木屋的暖窗光洒在露台右侧，雪人站在露台右缘（每关多搭一段）。
- **底部前景**：被扫到台边的雪堆，把露台下沿埋掉一半，这就是自然的软边；阿芳的一串脚印从雪堆走上露台；雪兔只露出耳朵。
- **棋子与容器**：每块板上有一小捧积雪窝，棋子半埋在里面：雪花晶、星星、热可可杯、手套、松枝、望远镜徽章。冰封机制就是把窝冻成冰。
- **消除**：雪窝"噗"地扬起雪粉；星星棋子升空，落进上方星空，接成星座（星图机制可视化）；猫头鹰在望远镜上转头。
- **遮棋后**：雪夜观星台前一片积雪的木露台。✔
- **可玩性**：网格天然规整，7×7 自然。夜景要保证可读：板面用暖窗光照亮（不发白），棋子带 DESIGN §5.1-7 的轻自发光描边。
- **性能**：露台 49 块 instanced；圆顶 ≤ 2.5k；雪粒子 ≤ 60。风险低。

### C 云海 → 换载体：老铆摊开的掌心
- **载体**：守风机器人老铆从云海里伸出巨大的铜绿掌心，掌心是铆钉拼成的方形装甲板，7×7 格就是板缝，铆钉落在格角。这和"老铆托举"的转场 T6 衔接上了。名字叫"老铆"，铆板成格也顺理成章。外形全部原创。
- **四周**：上方是四根弯起的手指（指尖长苔、停着纸鹤），指缝之间露出黎明云海、远处石柱和奇松，太阳刚出云。左边是大拇指，从画面外弯进来压住左沿。右边是掌缘，外面就是云，有云团漫上掌缘；老铆的半张脸在右上远处的云里露出一只眼（每 20–30 秒眨一次）。
- **底部前景**：手腕延伸出画面，上面是铜绿锈斑、青苔和一小丛野花，一只飞鱼刚跃过手腕。
- **棋子与容器**：棋子是风吹来、停在掌心铆板凹槽里的东西：云朵、曦光石、纸鹤、羽毛、风哨、风筝徽章。云遮机制就是一小团云落在掌心格上。
- **消除**：棋子被风从掌心吹落，飘进云海，飞鱼成群跃起去接；连消时手指轻轻合拢一下又张开。风向机制里，背景云朝哪边流，棋子就朝哪边落。
- **遮棋后**：一只长满青苔的巨人手掌托在黎明云海上。✔ 这是五个方向里最有记忆点的一张，也解决了 v3"云像粉色岩石"的问题：云只出现在掌心外，做成 instanced 白云团。
- **可玩性**：铆板网格天然规整；掌心和手指都是曲面，所以棋盘区域要保持近乎平面，手指只在棋盘外弯起。棋子是浅色，铜绿底色正好衬托。
- **性能**：手掌 ≤ 4k（板缝用顶点色做），云团 instanced；包体 ≤ 0.8 MiB 要靠复用 R3 老铆的材质色板，风险中等。

### E 风筝 → 放弃做棋盘载体
风筝在天上，又是竖着的，天生就是一块面对镜头的板子；底下没有地面可以延续，过不了 R2 和 R6。风筝改回剧情地标，放进 D 的天空和终章的"放风筝线"机制里。E 这个位置让给下面的新点子。

## 3. 天生"地面即棋盘"的新点子（都不碰水面）

| 新点子 | 对应区域 | 载体与场景 | 棋子 / 消除 | 可玩性 / 风险 |
|---|---|---|---|---|
| **N1 磨坊边的方格小菜园** | R2 风车草甸（棋盘翻新） | 用木条隔成方格的菜园，一格一畦，木条就是格线。上方是大风车和磨坊，左边是栅栏和小羊，右边是小径，底部前景是野花和一把靠着的锄头 | 蒲公英、野莓、麦穗、三叶草……棋子"种"在土里。消除时作物被风吹向风车，风车加速，小羊探头 | 网格最天然，7×7 很自然。土色偏暗，棋子容易读。风险低，可复用草甸地形 |
| **N2 山村晒秋台** | R5 秋林（A 的备选） | 山村屋顶上的晒台，一格一只圆竹匾，晒着红辣椒、黄玉米、菊花。四周是一层层叠下去的屋顶和彩林，铁轨从山腰绕过 | 晒的东西本身就是棋子。消除时被风吹起，落进下面的林子 | 颜色最浓，格子规整。**风险：竹匾和竹筏的小竹篓同属竹编容器**，只在 A 不成立时才用 |
| **N3 天空之城的铜瓦屋顶** | R3 天空之城（棋盘翻新，低优先） | 俯看一面缓坡屋顶（约 12°），方形铜瓦长着细苔。四周是相邻的屋顶、烟囱、花箱，远处是浮空风车阵；底部前景是檐沟、常春藤和停着的风标鸟 | 被风吹来卡在瓦片上的齿轮、羽毛、天空石。消除时被吹下屋顶，猫从烟囱上扑一下 | 网格规整，但物体放在屋顶上不太容易说通。可以作为 R3 翻新的候选 |

考虑过但不推荐：梯田、茶园和薰衣草田垄都只有一个方向的条纹，凑不出 7×7 方格，可以留作背景；鹅卵石小巷的网格不规整；盐田和冰面会和水面载体撞车。

## 4. 推荐的 v4 方向与出图顺序
1. **C 老铆掌心（R7）**：最原创，故事联系最强，最能证明"融合"不是靠一块布。
2. **B 积雪木格露台（R6）**：板缝天然成格，雪堆天然成软边，脚印把人引进画面。
3. **A 林中小站月台（R5）**：真轨道 + 火车机制落地。不成立时用 N2 晒秋台。
4. **N1 磨坊方格菜园（R2 翻新）**：用来验证这套规则能不能直接套到已有地区。
5. **D 野餐布**：照 D_refine 继续做，并补上 R4 底部前景和 R5 树影不进格子这两条。

**出图约定**：每个方向交 3 张，分别是 720×1280 概念图、遮棋版和格子尺寸标注版，再加一张总览。镜头沿用 v3（55° 俯角、屏幕方格反投影），棋盘下沿抬到 10%。粗一点没关系，但每张必须先过 R1–R6 自检表。每张预计 25–40 分钟渲染，仍然一次只跑一个 Blender，D_refine 优先。竹筏 S2 排在这一轮后面。
