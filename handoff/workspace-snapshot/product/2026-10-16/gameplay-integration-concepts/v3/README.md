# 玩法融合方案集 v3：棋盘躺在场景里

v3 只修一件事：棋盘是场景里一个有透视的平面，不再是立在背景前的平板。v2 的图在上一级目录，v1 在 `../_v1/`。

**镜头**：和湖畔棋盘相机同一套参数，竖直 FOV 61.93°（30mm 镜头 / 36mm 传感器，竖屏自动适配），近距离斜向下看。为了让格子够大、够方，俯角从湖畔的 25.5° 加到 55°。

**格子**：先在屏幕上定好 7×7 方格（列宽 90.5 px，占画面宽 88%，下沿在画面高 7% 处），再把每个格角反投影到载体平面上。这样远排格子在模型里略宽、略长（A 远排约 1.36 倍），抵消透视。屏幕上每格实测 91×91 px，同一列宽度差为 0。
- 脚本：`scripts/gic3.py`（Blender 5.2 EEVEE，原创低多边形形状），基础形状在 `scripts/helpers.py`。
- 后期：沿用 `../scripts/post2.py`（饱和度 ×1.22，对比度 ×1.06，轻暗角），不加雾，不加光柱。
- 实测汇总：`scripts/qa_summary.txt`。

## A 秋林铁路 · 货箱车厢（A_rail_crates.png）
- **场景：** 秋林里的铁轨伸向远处，平板车前面挂着绿色小火车头，路边有红叶树、落叶和信号灯。
- **棋盘载体：** 7×7 只开口木货箱平铺在红色平板车上，一箱一格；落叶跨过车沿和箱沿。
- **道具与消除：** 枫叶、橡果、蘑菇、松果、栗子、车票；消除时道具从箱口旋出，卷起一阵落叶小旋风。
- **可玩性：** 格子 91×91 px，点击区 = 整个箱口。

## B 雪夜观星台 · 星图桌（B_snow_starmap.png）
- **场景：** 雪夜里的圆形木观景台，围着栏杆，左后方是一座小巧光滑的圆顶观星台，右后方有亮着暖灯的小木屋，再远是雪松、远山、淡极光和星空。
- **棋盘载体：** 一张斜放 20° 的木框星图桌，立在观景台上；深蓝面板上金线分格，桌沿压着积雪。
- **道具与消除：** 星星、月牙、彗星、行星、望远镜、观风日志；消除的星星升空，连成一段星座。
- **可玩性：** 格子 91×91 px。

## C 云海 · 崖顶石台（C_cloud_terrace.png）
- **场景：** 黎明的崖顶，两角各长着一棵奇松，左边松枝上挂着断线风筝；崖外是蓬松的圆润云海，远处有石柱。
- **棋盘载体：** 7×7 块圆角石板嵌在崖顶岩面里，石缝长苔，苔藓团跨过台沿。
- **道具与消除：** 云朵、曦光石、纸鹤、羽毛、风哨、松枝；消除时道具散成一团小云飘走，偶尔飞起一只纸鹤。
- **可玩性：** 格子 91×91 px。

## D 山丘重逢 · 坡上野餐布（D_hill_picnic.png）
- **场景：** 初夏夕阳下的草坡，开满小花，坡顶有大树和两人座秋千（树影落在布外的草上）。
- **棋盘载体：** 格纹野餐布顺着 18° 的坡铺开，布格本身就是棋盘；餐篮压在右下角，风筝搭在上沿，草叶跨过布边。
- **道具与消除：** 萤火虫瓶、风筝、信封、围巾结、草莓、蒲公英；消除时蒲公英种子和萤火虫一起飘走。
- **可玩性：** 格子 91×91 px。

## E 备选 · 崖顶大风筝（E_sky_kite.png）
- **场景：** 云海边的崖顶草台，阿芳（黄围巾）站在一旁拉着线，远处是蓬松云海和石柱奇松。
- **棋盘载体：** 一只八角大风筝面向镜头、下沿压在草地上，竹骨把风筝面分成 7×7 格并跨出风筝边，彩带尾巴落在草上。
- **道具与消除：** 纸飞机、蝴蝶结彩带、铃铛、飞鱼、气球、风筝徽章；消除时道具化成彩带飘走。
- **可玩性：** 格子 91×91 px（风筝面正对镜头，没有透视压缩）。

## 通用交互
按下或拖动时出暖白细光圈，道具轻轻抬起；消除时放大到 1.18 倍，约 0.12 s 后接各方向自己的特效。所有元素和棋盘用同一套光，接触阴影由场景的太阳光直接投出。
