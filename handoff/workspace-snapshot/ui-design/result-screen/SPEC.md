## 宝箱 ResultChest3D v2.2（立体化）
问题：v2.1 是正面略俯视，看不到顶面和侧面；平滑着色加上高亮，表面像塑料，缺少主页木板和按钮那种“厚度 + 侧面 + 底边 + 投影”。
做法是参照主页木板的立体做法：顶面受光最亮，侧面暗一档，底边最暗，再加描边和贴地阴影。

| 项 | 旧 (ResultChest3D L52–60) | 新 v2.2 |
|---|---|---|
| 相机 | 近正面 | 3/4 俯视。俯角 36°，水平方位 −38°（从右前方看，顶面、正面、右侧面三面同时可见）；视场相当于 55mm 焦距（fov ≈ 36°），注视点 y = 0.42（打开时 0.55），距离 5.6 |
| 着色 | 平滑法线 | 平面分面：导入 glb 时关掉平滑法线 / 不做法线平滑，每个面一种明度（低多边形） |
| 材质 | M_env_palette 原值 | 宝箱单独一份材质实例：albedoScale (1.10, 1.06, 1.00)、饱和度约 +12%、roughness 0.6、高光强度 0.35（压掉塑料感） |
| KeyLight | (−1.6,3.2,2.6) #FFF1D8 ×2.5 | 改成平行光：从左上近乎头顶照下，方向 (−1.6,−1.4,6) 指向原点（Blender 坐标），#FFEDCC，强度相当于 4，角半径 0.35（软阴影） |
| FillLight | #DBE9FF ×1 | 右前方低位 (4,−3,1.5)，#CCE0FF，亮度降到约 0.4×（让侧面暗下来，形成明暗分面） |
| RimLight | 无 | 背后上方 (0.5,3.5,3.5)，#FFD18C，亮度约 1.1×，勾出盖子顶边 |
| InnerGlow | 0.6 | 只在打开后点亮：1.4，色 #FFCC6B，range 2.2 |
| 环境光 | — | 天光 #FFEBCC，强度 0.35（暗部偏暖，不发灰） |
| 描边 | 无 | 可选，推荐开。外描边 3px @2x（约 1.5pt），色 #4A2810，只描轮廓 |
| 接触阴影 | 无 | 箱底一块柔和椭圆阴影，#3C2614 α≈45%。光从左上来，所以偏右后方；外缘不超过箱宽 0.62 倍，blur 28px |

- 3D 实现：
  - 描边：在 RenderTexture 输出后用 UI 描边 shader，或给 Sprite 叠一层外描边（按 alpha 外扩 3px）。不要用反向外壳描边，会挡住箱体（Blender 里已经验证过）。
  - 阴影：ResultChest3D 关掉了投影（shadowCastingMode OFF），所以在 Chest3D 节点下面放一张 2D 阴影 sprite。可以直接从 `chest/chest_v3_0.png` 的阴影部分裁出来，或者用 220×60 的椭圆，blur 14。
- 2D 兜底：
  - 关闭：`chest/chest_v3_0.png`（542×443）
  - 打开：`chest/chest_v3_12.png`（641×620）
  - 两张都已带描边和接触阴影。打包时缩到 400 宽，替换 `popup/chest_closed.png`，并新增 `popup/chest_open.png`。
- 渲染脚本：`chest/render_v3.py`。用法：`blender -b --python render_v3.py -- <帧 0|12> <输出路径> 0`（Cycles 96 采样，配阴影捕捉面）。描边和阴影裁剪是后期处理，代码在下方。
- 新旧对比：`chest/chest_old_vs_new.png`（旧 2D 兜底 / v2.1 调亮版 / 新版关闭 / 新版打开）
- 形体和配色：沿用原模型和原调色板，见上面 v2.1 说明。

## 动效
| 名称 | 时长 | 缓动 | 循环 | 说明 |
|---|---|---|---|---|
| 入场 Panel | 280ms | backOut(1.2) | 1 次 | scale 0.92→1，α0→1；星星依次 120ms 间隔 pop 0→1.15→1 |
| 宝箱呼吸 | 1600ms | sineInOut | 无限（打开前） | Chest scale 1→1.04→1；Glow α 0.7→1→0.7、scale 0.95→1.05 |
| 宝箱轻跳 | 420ms | quadOut 上/bounceOut 落 | 每 2.4s 一次 | y −8pt 回落 + 旋转 ±3°；用户 3s 无操作才开始 |
| 点击反馈 | 按下 80ms / 抬起 160ms | quadOut / backOut | — | scale 0.94，抬起回 1.06→1；轻震 wx.vibrateShort('light') |
| 开箱 | 360ms | backOut | 1 次 | ResultChest3D.open()，盖到 open 姿态并保持；内部亮光 α0→1；Rays 渐显 240ms 后 20s/圈 慢转 |
| 奖励浮出 | 每个 420ms，错开 90ms | backOut(1.4) | 1 次 | 从宝箱口 (195,470) 起，scale 0.3→1，移到目标位，随后 2000ms sineInOut 上下浮 ±3pt 循环 |
按钮按下：下沉 4pt（底厚 6→2），抬起回弹。可在宝箱打开前点按钮——奖励自动领取（防漏领），不弹二次确认。

## 逻辑
- 点宝箱 = 一次性领取全部奖励（复用 ClaimAll 的一次性守卫与批处理），然后切到打开态；再点无效果。
- 3D 加载失败时：2D 宝箱 sprite，同样 Glow + 呼吸。
- 不再出单独的「获得」弹窗（奖励就在宝箱上方展示）。
