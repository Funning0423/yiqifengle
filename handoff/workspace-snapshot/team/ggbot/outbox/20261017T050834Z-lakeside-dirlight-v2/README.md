## v2 改了什么（全部在 LAKESIDE_DIR_LIGHT_PARAMS）
| 参数 | v1 | v2 | 来源 |
|---|---|---|---|
| 主光方向和颜色 | json Sun | 不变：[-0.4182,-0.3983,0.8164]，[1,0.6,0.32]，×1.0 | json |
| 环境天空色 | dusk 黄 [1,0.55,0.28] | **蓝 [0.0116,0.2747,0.4793]**（sRGB 28/143/184） | lakeside_r5h3.blend 世界天空渐变最上面的一档 |
| 环境地面色 | [0.5,0.275,0.14] | 不变（暖） | — |
| 环境照度 | 主光×0.31 | **主光×0.75** | 在 Blender 代理里调，让整帧平均色接近 r5h3 |
| 水面染色 | 无 | **mainColor [0.06,0.55,1.0]**（sRGB 69/196/255） | 在代理里对照 r5h3 棋盘附近的水调出来的 |
| 清屏色 | 桃色 #f2b98a | **天空蓝**，同天空色 | 同上 |

- json 和 handoff 里没有环境强度、水色和天空色的数值，所以天空色取自 .blend 的世界节点，环境强度和水色是在代理里调出来的。
- 水面：LK_lake 用的是近白色的调色板乘顶点色（线性均值约 0.08/0.41/0.43）。暖色主光一照就偏绿，所以在租约自己的 instancing 材质副本上设置 mainColor。资源本身没改，副本随租约一起销毁。没有新贴图。
- 注意：mainColor 能不能乘上顶点色，取决于 glTF 导入的材质有没有开顶点色。请在 Mac 上确认水是蓝的。
- 'points' 模式不受影响。

## 坦白说还差在哪里
- 整体色调已经从灰黄、灰绿回到青蓝，和 r5h3 接近。天空蓝能从山缝里看到。
- **水**：色相对了（青蓝），但比 r5h3 暗约 15%、饱和度低。r5h3 的水靠 shader 的天空反射和高光带亮起来，这里只能乘颜色。游戏内也一样：要更接近，需要水面 shader（handoff §7，太阳反射带和闪光），不是灯光能解决的。
- **暖色夕照**：主光的暖色在桥、房子、岸边还在，但 r5h3 远岸那片暖金色的体积雾和光晕没有了。Cocos 端按 handoff 是用雾的方向散射 + Bloom 来做，本提交没做。
- **远山**偏灰紫，比 r5h3 暗。r5h3 有只照远山的 SUN_mtn_sky 和雾，这里都没有。
- 桥中间那块橙色的大物体仍然在（Voice Bot 的代理图里也有，r5h3 里没有），疑似实例摆放问题，请在 Mac 截图里确认。
- 环境 ×0.75 和水色都是按 Blender 代理调的。Cocos 的光照单位和色调映射不同，请以 Mac 截图为准再微调这一个常量块，或者直接换成 Voice Bot 的换算值。
