## §A 位移归属和世界姿态交接（不双位移、不瞬移）

### A1 谁负责移动
| 对象 | 过场期间 | 非过场（现有流程） |
|---|---|---|
| 角色 controller 节点（`standingControllerRoot` 所在的节点，下称 **C**） | **不动**，停在当前这段 clip 的起点 | 由 `WorldFlowCore.walk()` 按路点平移和旋转 |
| 根骨（GLB 里人物骨架的根，下称 **R**） | **由 clip 驱动**，root motion 已烘焙，相对 C 的局部空间 | 局部单位变换（不动） |
| `cine_camera` | 由 clip 驱动（世界空间），游戏相机逐帧复制它的位姿 | 不用 |
| 门叶 | 由 clip 驱动 | `animateDoor()` |
| 逻辑碰撞体或胶囊（目前游戏里没有物理，0001b 已裁掉；以后如果加上） | 挂在 **R 的水平投影**上跟着走：取 R 的 XZ 位置和 yaw，忽略俯仰和翻滚 | 挂在 C 上 |

### A2 对运镜bot 的导出约定（v1.2 新增，请确认）
- 每段 clip 里 **R 的轨道都在 C 的局部空间**，**第一帧的 XZ 位置为 0、yaw 为 0**，高度 Y 可以不是 0（比如坐姿）。
- 每段 clip 另外在 timing.json 里写两个字段：`rootStart` 是这段 clip 起点 C 的世界位姿，`rootEnd` 是最后一帧 R 的世界位姿，格式都是 `{position:[x,y,z], yawDeg}`。运行时用它们核对，你在 Blender 里做的锚点误差报告也用同样的定义。
- 衔接段之间**不要求停到 rest**：上一段最后一帧的 R 速度要和下一段第一帧的 R 速度一致（Oi 第 6 条）。
- 另外单独做「安全停姿」，每个过场终点各一个姿势（单帧 clip），比如 `cine_open_safe_end`、`cine_home_safe_end`，只在跳过和取消时用。

### A3 统一时钟（解决切段卡顿和不同步）
- 过场由一个 **CinematicClock** 统一驱动。人物、门和相机的 AnimationState 都**不让 Cocos 自己推进**，每帧由时钟算出「当前是第几段、段内第几秒」，然后调用 `state.setTime(t)` 和 `sample()`。
- 音轨按时钟时间开始播放。暂停后恢复时，用 `currentTime = 时钟时间 - 音轨起点` 重新定位，偏差超过 80 ms 才定位，避免频繁 seek 出现爆音。
- **切段**：如果这一帧时钟越过了第 k 段的结尾，超出的时间 Δ 直接算进第 k+1 段，不会多停一帧。
- **音轨跟随时钟**（采纳 Voice Bot 的建议）：
  - 切段时，下一条音轨从 Δ 开始播，不从 0 开始，这样声音和画面不会越错越远；上一条的尾音（clip 结束后多留的 0.35 s）照常播完，不打断。
  - 回前台后恢复：每条正在响的音轨都 seek 到 `时钟时间 - 该音轨起点`，按 30 fps 算就是帧号 ÷ 30，然后接着播，不从头播。还在播的尾音也一样定位后接着播完。
  - 取消：所有音轨在 0.2 s 内线性淡出，然后停止，和人物淡回站立同步。
  - 跳过：所有音轨立即停止，包括尾音；安全停姿不配任何声音。

### A4 切段时的世界姿态交接（每次切段都在同一帧完成，渲染之前）
1. 按时钟时间，把第 k 段 sample 到它的**最后一帧**；
2. 把 R 的水平投影写进 C：`C.world ← (R.world.xz, R.world.yaw)`，C 的高度保持地面高度；
3. R 的局部变换重置成第 k+1 段的第一帧（XZ 和 yaw 是 0）；
4. 用 Δ sample 第 k+1 段；
5. 核对：第 2 步写进去的 C 和第 k+1 段的 `rootStart` 比较，误差 ≤ 1 cm、≤ 1°，只记日志。超出时打警告，以 `rootStart` 为准吸附，这一帧画面的偏差 ≤ 1 cm。

所以「双位移」不会发生：同一时刻只有 C 或 R 其中一个在动。「瞬移」也不会发生：交接前后 R 的世界位姿不变。

### A5 跳过、取消、暂停恢复
| 事件 | 处理 |
|---|---|
| **跳过**（`skipCinematic()`，幂等） | 停掉时钟、所有音轨和后续排队 → 人物播放 `*_safe_end` 姿势 → C 直接放到 `rootEnd`（开场是终点 root；回家是坐姿 root (0.4327, 0, −4.2076)），R 归零 → 门 sample 到最后一帧 → 相机设为终帧位姿，FOV 恢复 45° → 进入稳定状态（`island` / `home`）→ 环境声直接设为正常音量。这是一次有意的硬切，是唯一允许画面跳的情况。 |
| **取消**（`cancelTransition()`、`fault`、地区加载失败等） | 冻结在当前帧 → 按 A4 第 2、3 步把 R 交接给 C → 人物在 0.25 s 内交叉淡入站立待机 → 相机保持当前位姿，FOV 线性回到 45°（0.3 s）→ 状态回到出发点（开场取消时停在室内 `home`，回家取消时停在 `island`）。不会瞬移，角色停在当时的位置。 |
| **切后台 / 回前台** | `EVENT_HIDE`：时钟暂停、音轨暂停，人物、门、相机都保持当前帧；`needsResume = true`，和现有流程一样。回前台后点「继续」：时钟从原来的时间继续，音轨按 A3 重新定位。不会重播，也不会跳帧。 |
| **过场中重复点按钮** | 过场期间导航按钮全部隐藏，只保留「跳过」。 |

## §B 相机契约（0006 和 0007 共用一份）

### B1 统一的数据结构 `CameraPose`
```ts
type CameraPose = {
  position: [number, number, number];          // 米，Cocos 世界坐标，+Y 向上，室外前方 +Z
  rotation: [number, number, number, number];  // 世界旋转四元数 (x, y, z, w)，单位四元数；roll 必须为 0
  fovVerticalDeg: number;                      // 角度，按竖直方向，取值 30–75；拖动和静止时固定 45
};
```
- **配置文件里也可以写 `target`**（0007 的 `regionCamera.json`、`island_camera_pose.json`），加载时用 `Quat.fromViewUp(normalize(target - position), +Y)` 转成 `rotation`。运行时只用 `rotation`。
- **固定参数**（不进契约，写死）：透视投影，`fovAxis = VERTICAL`，near 0.05 m，far 1000 m，宽高比跟随屏幕。
- **Blender 换算**：Cocos 的 (x, y, z) 对应 Blender 的 (x, −z, y)。glTF 导出时会自动换算，所以 `cine_camera` 节点不需要手动转换。`island_camera_pose.json` 里两套坐标都写，以 Cocos 那一套为准。

### B2 来源、采样和插值
| 来源 | 采样 | 插值 |
|---|---|---|
| 0006 过场 `cine_camera` 的位置和旋转 | 由 CinematicClock 驱动 glTF 动画 sample（30 fps 关键帧） | 位置线性插值，旋转用 Cocos 动画自带的 slerp |
| 0006 过场 FOV | timing.json 的 `fovVerticalDeg[]`，每帧一个值，帧率等于 clip 的 fps | 相邻两帧之间线性插值，`f = frame + frac` |
| 0007 拖动 | 每帧由 `regionPan` 计算 | 位置用 Catmull-Rom（有 `via` 时）或线性插值，旋转 slerp，FOV 固定 45 |
| 两者之间的过渡（§C） | 每帧计算 | 位置线性插值，旋转 slerp，FOV 线性插值，权重用 ease-in-out-cubic |
- 所有时间单位都是秒；帧号是整数，从 0 开始，`frame = round(t × fps)`。
- 相机的应用统一走同一个函数 `applyCameraPose(pose)`：依次 `setWorldPosition`、`setWorldRotation`，再设置 `camera.fov`。0006 和 0007 都调用它，不再用 `lookAt`。
- **衔接点必须相等**：出门过场最后一帧的 `CameraPose`，要等于 `regionPan = 0` 时的 `CameraPose`，位置差 < 1 mm、角度差 < 0.1°、FOV 正好是 45。加载时会核对，不满足就打警告，以 0007 的值为准吸附。

## §C 回家：从玩家拖到的当前相机连续接回
v1.1 和 0007 v1 里写的是「先吸附回小岛再开始回家」，**v1.2 改成从当前相机连续接回**，不再先回到默认的小岛机位。
- 点「回家」的那一刻，把当前相机记下来作为 `C0`，可能停在任意 `regionPan`，也可能在惯性滑动中，这时先停掉惯性。
- 回家过场正常从第 0 帧开始播（人物和门不受影响）。前 `Tb` 秒内，相机用
  `pose(t) = blend(C0, cineCam(t), w)`，其中 `w = easeInOutCubic(t / Tb)`。
  位置做线性插值，旋转做 slerp，FOV 在 `C0.fov`（45）和 `cineFov(t)` 之间做线性插值。
- `Tb = clamp(0.6 + 0.4 × |regionPan|, 0.6, 1.4)` 秒：从小岛出发时 0.6 s，从天空之城出发时 1.4 s。要求运镜bot 的回家过场前 `Tb` 秒里，人物不会被镜头穿过；如果有冲突，再调 `Tb`。
- 中途离开的检查：如果 `C0` 到 `cineCam(0)` 的直线会穿过灯塔或山体，就改为经过 `regionCamera.json` 里登记的 `via` 点。Blender 那边只需要保证 `cineCam(0)` 等于小岛位姿就行。
- 跳过回家过场：按 A5 直接硬切到坐姿和室内终帧相机。

## 验收（Oi，等合并时一起测）
1. 开场整段播放：每次切段都没有卡顿、没有停到 rest 的痕迹。在调试接口 `__worldIntegration.cine()` 里看每次交接的误差，都 ≤ 1 cm、≤ 1°。
2. 在每一段里各点一次「跳过」：都直接到安全停姿，角色坐标等于 `rootEnd`，声音立刻停，地区选择能正常使用；连点两次不报错。
3. 在每一段里切后台再回来，点「继续」：从原来的帧接着播，音轨偏差 < 100 ms。
4. 模拟取消（在调试接口里调用 `cancelTransition`）：角色停在当前位置，在 0.25 s 内回到站立待机，没有瞬移。
5. 把镜头拖到草原（`regionPan = 1`）后点回家：镜头在约 1.0 s 内连续接进回家过场，中间不经过默认的小岛机位，没有跳切。
6. 出门过场最后一帧和 `regionPan = 0` 时的相机，三项差值分别 < 1 mm、< 0.1°，FOV 正好 45。
