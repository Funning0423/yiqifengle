## 衔接
- **入点**：S1 第一帧 = 出门运镜最后一帧（`cameraIsland`，现在是 v24-readable (-12,15.5,48)→(1,.5,1) FOV 42；如果 Funning 选了本次 exit-cam-check 的新终帧，就接新的）。位置/target/FOV 都连续，速度 0 起步。
- **出点**：S5 最后一帧 = 草甸 regionCamera 位姿（上面三元组，up +Y，roll 0），速度 0，HUD 淡入。和 `RegionCameraData.stops[meadow]` 将来要填的 pose 一致。
- 场景切换只在 S3 云层满屏那 0.4 s 里做；草甸 bundle 要在 S1–S2 预加载，**没加载完就让云层停住**（不硬切）。

## 跳过（tap to skip）
- 0.3 s 之后点屏幕任意处可跳过（前 0.3 s 不响应，防止出门最后一下误触）。
- 跳过 = 0.3 s 云层/白色淡入淡出 → 直接落在 **S5 的最终帧**（草甸位姿、她站在 spawn、船停岸边、HUD 恢复）。跳过和看完落在同一个状态。
- 如果在 S3 场景切换之前跳过：云层盖住时再切 bundle，没加载完就停在云上等加载。

## 待定 / 风险
- 草甸场景（v0.8 灰盒）里还没有船模型和岸边停船点，需要美术给一个 `boat_dock` 锚点；海岛这边也要一个停船点（建议 exit_path_17 附近的沙滩）。
- 草甸位姿是 Cocos 草甸坐标；海岛和草甸是两套坐标，所以 S3 里必须有遮挡（云）切换，不能一条连续路径飞过去。
- 节奏选项：嫌长可以把 S3 缩到 1.0 s（总 4.8 s）；要更有仪式感可以 S2 拉到 1.6 s（总 5.6 s）。
