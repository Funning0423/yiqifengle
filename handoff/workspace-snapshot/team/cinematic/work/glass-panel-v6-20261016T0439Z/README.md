# 玻璃牌 v6「出发去看海」原型（运镜bot，2026-10-16）
Funning 否决 v5，v6 只改角度：以 v4 为底，玻璃板转成正对镜头，尺寸保持 v4（0.80×0.28 m 胶囊），移到画面左侧，不挡人物；材质恢复 v4 薄玻璃（blur 14px + saturate 1.4，1.5px 细亮边 + 顶部内高光），去掉 v5 的厚度/后板/侧边、假投影和全屏景深。

## 性质（如实说明）
- 和 v4/v5 一样是**原型**：在真实 5c54f7a 网页构建（web-task21-ui-5c54f7a.tgz，本地 127.0.0.1:18790）上叠 HTML 层。玻璃牌不是 Cocos 里的真 3D 网格；毛玻璃用浏览器 backdrop-filter（只模糊玻璃后面的画面）。不是 Mac/微信真机录屏。
- **没有游戏代码补丁**：v4、v5 都没有改游戏代码，玻璃牌在代码库里不存在，所以 v6 没有可叠的补丁，也没有新分支/commit/tree。代码基线 = yiqifengle `mac/task21-web-ui` @ 5c54f7a（工作区未改动）。Funning 选定后需要在 Cocos 里正式实现（面板网格 + 材质 + 点击框）。
- 左右两边 v4 和 v6 都是这次用同一脚本逐帧（Playwright clock，30fps，1 倍速）重录，时区 Asia/Shanghai 保证白天，所以两边完全同步。

## v6 参数
- 平面朝向：法线指向默认机位 Main Camera (−1.320,1.386,−2.114)，轴 = 机位 right/up；和 v4 同深度，从 v4 中心 (0.05,1.02,−4.70) 沿镜头左方平移：0.46 用 0.42 m → (−0.313,1.02,−4.911)；0.75 用 1.00 m → (−0.814,1.02,−5.203)，让左边缘都落在约 18–20 pt 安全边距。两比例横向视野不同，单一世界点无法同时贴左，所以按比例各取一个。
- 浮动 ±0.012 m / 3.2 s，点击反馈时序同 v4（f0–27，f27 调 leave()），出门镜头为原版。

## 不挡人物 / 不虚化
- 人物剪影 = 默认视角下隐藏 LOD0_G2_* 前后截图差分。v6 视觉框、点击框内剪影像素均为 0；离剪影最近 24.7 pt（0.46）、11.6 pt（0.75）。（v4 会压到人物 6/2 px。）
- 不再有全屏景深：人物和房间清晰，只有玻璃板后面被 backdrop-filter 模糊。
- 只在默认视角做了剪影差分；滑动时面板是世界锚定，和人物一起转。
