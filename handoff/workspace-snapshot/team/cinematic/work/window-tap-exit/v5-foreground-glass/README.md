# v5 前景玻璃牌「出发去看海」原型视频（运镜bot，2026-10-15）
根据 Funning 对 v4 的反馈：材质可以，但没有空间感，而且玻璃牌是给玩家点的。v5 把玻璃牌放到镜头和她之间的前景里，始终正对镜头。只是原型视频，没有改游戏代码，没有推送。

## 位置和尺寸
- 默认机位：Main Camera 在 (−1.320, 1.386, −2.114)，FOV 75。
- 面板中心：世界坐标 (−0.859, 1.149, −3.104)。取法是从默认机位沿视线向前 1.10 m，向左 0.10 m，向下 0.17 m。位置在她身前、膝盖和桌面这一高度，不挡脸，也不挡窗外的海。
- 尺寸：0.46 × 0.16 m 胶囊形，厚度做出来的视觉效果约 2 cm。
- 浮动：±0.008 m，周期 3.2 s。
- 屏幕实测尺寸（同时也是点击框）：
  - 0.46：213 × 74 pt
  - 0.75：142 × 49 pt
  - 两个比例都 ≥ 44 pt。

## 做法
在真实的 5c54f7a 网页构建上叠一层 HTML。
- **Billboard（始终正对镜头）**：每帧用 Main Camera 的 worldToScreen 投影面板中心，再投影中心沿相机右方向偏 0.46 m 的点，两点距离决定面板宽度。面板在屏幕上保持正对，只按 yaw 有轻微的 rotateY 立体感（−0.6°/°）。
- **前景视差**：游戏的看房间是相机原地转动，纯转动不会产生前后景的视差。所以这里额外加了一个跟 yaw 联动的横移（3 px/°，按 360 宽度换算），模拟头部偏离转轴的效果。这是模拟出来的，正式版需要让相机绕一个轴点小幅平移，或者把面板挂在相机子节点上，再加一点滞后。
- **厚度和折射**：三层叠起来。
  - 后板：错开 5–6 px，偏蓝，加模糊和投影。
  - 侧边：渐变高光，表现玻璃的厚度。
  - 正面：blur 16 + saturate 1.5，2 px 亮边加内高光，再用一圈 conic 渐变做边缘的折射亮点。
- **投影**：沿镜头到面板的射线再往后 0.9 m、下移 0.08 m，得到落点 (−0.482, 0.875, −3.914)，在她的膝盖和桌边附近。在这个点画一个按距离缩放的模糊暗椭圆，透明度 0.30。
- **景深**：全屏 backdrop blur 1.6 px，让她和房间稍微虚一点。面板淡出时景深一起消失（f16–26），出门镜头是清晰的。
- **点击反馈**：时间和 v4 一样（30 fps，f0 为点击），改成逐帧用 JS 驱动。
  - f0–4：按下，scale 到 0.92，亮度 1.15
  - f4–10：回弹到 0.97
  - f3–19：光圈，约 f10 达到峰值
  - f6–24：涟漪
  - f16–26：面板淡出，同时景深和投影一起淡出
  - f27：调用 `__worldIntegration.leave()`，原版出门镜头开始
- **逐帧录制**：用 Playwright clock 接管页面时钟，每步推进 33.3 ms 截一帧，所以不管盒子负载多高，都是标准的 30 fps 1 倍速。时区设成 Honolulu，让游戏保持白天，和 v4 一致。

## 限制
- 玻璃牌、投影和景深都是 2D 叠加层，不是 Cocos 里的真 3D 渲染。景深是全屏统一模糊，不是按深度计算的。投影是假的，不会贴合她和桌子的形状。
- 前景视差是模拟出来的，因为游戏相机原地转动本身没有视差。
- 左边 v4 用的是之前的实时录制（帧率低，出门部分已经剪掉了卡顿等待）。右边 v5 是逐帧录制。所以两边节奏不完全同步。
- 调试条在录制时把透明度设成了 0。没有用任何付费素材，🍃 是系统 emoji。
- 正式版需要在 Cocos 里用真实的面板网格加材质来做，并且要在 Mac 和微信真机上验证。
