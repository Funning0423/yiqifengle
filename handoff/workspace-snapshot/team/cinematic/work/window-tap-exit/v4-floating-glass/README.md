## 做法
在真实的 5c54f7a 网页构建上叠一层 HTML 模拟：
- 玻璃效果：backdrop-filter blur 14px + saturate，白色渐变半透明，1.5px 亮边加内高光，再加一点投影。
- 世界锚定：每帧用游戏 Main Camera 的 worldToScreen 投影面板 4 个角，再用单应性 matrix3d 贴上去。所以透视和视差都是真实相机算出来的。
- 滑动：调用游戏自己的 WorldFlowComponent.lookRoom 驱动视角，画面里的白圈只是模拟手指。
- 出门：真实调用 __worldIntegration.leave()，出门镜头是原版，没有改动。

## 面板参数
- 中心位置：世界坐标 (0.05, 1.02, −4.70)，在玻璃下沿 y=1.222 下方 0.2 m、玻璃前 0.425 m。
- 尺寸：0.80 × 0.28 m，胶囊形。
- 浮动：振幅 ±0.012 m，周期 3.2 s，正弦。
- 屏幕上的实测尺寸：
  - 0.46：123×57 pt，满足 44pt。
  - 0.75：82×38 pt，高度不够 44。正式版需要把点击框外扩到至少 44pt 高，或者把面板放大到约 0.92×0.33 m。

## 点击反馈时间（30 fps，第 0 帧为点击）
| 帧 | 动作 |
|---|---|
| f0–4 | 按下：scale 0.92，亮度 1.15 |
| f4–10 | 回弹到 0.97 |
| f3–19 | 光圈：亮边加暖色辉光，在约 f10 达到峰值后消散 |
| f6–24 | 涟漪：胶囊描边扩散到 1.9×2.6 倍，同时淡出 |
| f16–26 | 面板淡出，带 4px 模糊 |
| f27 | 调用 leave()，原版出门镜头开始 |

## 限制
- 玻璃牌是 2D 叠加层，不是 Cocos 里的真 3D 渲染。没有被人物或桌子遮挡，也没有景深。透出来的模糊背景用的是浏览器的 backdrop-filter。
- 盒子上没有 GPU，渲染只有大约 4–8 fps，所以画面会顿。出门段是 1 倍速实录，滑动段做了时间压缩。
- 点击反馈的动画在 CSS 里按真实时间跑，但录到的帧较稀，放大图里各阶段之间有跳帧。
- v3 一侧的窗台提示在滑动时没有按 patch 隐藏（patch 在 yaw 超过 6° 时会隐藏），这是模拟层的问题。v3 点击后立即出门，v4 晚 0.9 s，所以第二段左右两边不完全同步。
- 调试条在录制时把透明度设成了 0。没有用任何付费素材，🍃 是系统 emoji。
