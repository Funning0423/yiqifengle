# 玻璃牌 v4 精修2（运镜bot）— 修上/下边缘"螺纹"爬行
在 v4 精修的基础上：卡片自身不再画任何描边/顶部内高光（CSS border 和 inset 高光在 matrix3d 透视下随浮动落在半像素，产生周期性明暗/锯齿爬行）。
改为一层不做变换、叠在玻璃之上的全屏 SVG：每帧用同一单应矩阵把胶囊轮廓（内缩 0.75 本地 px）投影成屏幕坐标，画 1.3px 抗锯齿细亮边，白 α=0.43×r^0.6；顶部高光是同样投影的线（内缩 2.2），白 α0.8、宽 1.2×r^0.6 px（r=面板屏宽/123.2，0.46 时 r=1，0.75 时 r≈0.67），使峰值亮度与 v4 对齐。几何、材质（blur/saturate/渐变）、字、投影、浮动、点击时序、点击框都不动。
原型：5c54f7a 网页构建上的 HTML+SVG 叠加层，没有游戏代码补丁/SHA，没有推送。
见 check/edge_metric.json（scripts/edge_metric2.py），录制脚本 scripts/run8.cjs（v4|v4r|v4r2，FLOAT=1 只录 110 帧浮动）。
