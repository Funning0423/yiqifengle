主要问题与接入条件
1. 天空 CPU 剔除缺口（中等，源码推断，未实机复现）
   sky-unlit.effect:69–70 仅在 GPU 将天空移到相机 XZ，84–85 仅改裁剪空间深度。普通天空 MeshRenderer 的 CPU worldBounds 仍在原节点位置。Creator 默认管线先做 AABB/视锥剔除；相机远离原天空范围时，可能整片天空消失。推远平面不能阻止这一层剔除。[4]
   接入时让实际天空节点在世界 XZ 跟随相机，或提供可靠的 CPU 包围盒同步方案；保持原 Y/UV/美术资源不变。若工程已有跟随脚本，核实其执行时间和目标节点。编译成功不等于此风险已关闭。

2. 不支持硬件实例化时，性能与根色都降级（中等，源码路径确认）
   引擎无 INSTANCED_ARRAYS 时会关闭 USE_INSTANCING。[5] 当前 effect 随即改用统一 rootColor，a_root_color 的每丛根色失效；1,000 丛也可能退成约 1,000 次提交。仅 WIND_QUALITY=0 只关风计算，并不减少节点或提交数量。需要明确最低设备支持边界或单独的减量/关闭草兜底。当前包的“草 5 draw calls”只是理想合批目标，非实测。

3. 资源、生命周期与数据前置条件
   - 包不含 .meta、.mtl、GLB、instances JSON、白天/夜景贴图，不能直接视作已接好。两 TS 必须同目录。只导入 effects/ 和 scripts/；不要把 selftest/out/、patches/、compiler setup 作为运行资源。
   - MeadowInstancer 依赖 meadow_instances JSON 与模板节点名/单材质槽。生成节点是源节点的兄弟；若源模板节点有非单位局部 TRS，应核对展开后的变换是否保留。现包未包含这些场景数据，不能确认。
   - 开 USE_INSTANCING 和 USE_INSTANCE_ROOT_COLOR 前，必须确认每个草实例都提供 _ROOT_COLOR；缺值时实例属性初始为零，可导致黑根。换材质后重新写入实例属性是官方明确要求，现有切档事件已覆盖该路径。[6]
   - mesh/模型重建、运行中改变父节点缩放、场景重新显示等流程应在模型就绪后重算草包围盒并重设根色。包仅监听切档/风参数事件；其 README 已将部分恢复流程交给调用方。自动画质组件只在 start 扫一次，异步加载或后续新增草后需显式 apply。
   - 运行时画质 Material 副本有缓存，但没有显式销毁入口。区域卸载时需由资源所有者安排释放，避免多次加载后留下 GPU 资源；此为生命周期审查项，非已测内存泄漏。

最小接入备忘录
1. 在隔离 Creator 3.8.8 工程导入两个 .effect、两个同目录 TS，记录新生成 .meta。不要覆盖美术文件。
2. 草材质共享一个资源：USE_INSTANCING=true、USE_INSTANCE_ROOT_COLOR=true、WIND_QUALITY=1、GRASS_LIGHTING=1，WIND_SPACE=0、WIND_PHASE_PER_VERTEX=false。数值宏默认 0，未设置会静止。不静态合批、不对每丛创建 MaterialInstance。
3. COLOR_0 作为风数据读取，不能当顶点乘色；确认 r 在 [0,1]、alpha 已正确归一化。调色板关 mipmap。改风参数走 setGrassWindParams，确保包围盒同步。
4. 天空：绑定白天和夜景两张图，SKY_SOURCE=0；horizonV=0.857。USE_HORIZON_FOG 开启后 horizonFog 默认仍为 0，确需雾时才按已定视觉参数设置。场景 Skybox 关闭，相机 SOLID_COLOR。相机跟随与 CPU bounds 一并落实。
5. 海岛纯顶点色天空用 SKY_SOURCE=1、SKY_NIGHT_TINT_ONLY=true。nightTint 默认为白色；没有已定暗色时夜晚不会自动变暗，不擅自改美术参数。
6. 本轮后续上限是 Creator 导入/脚本编译/Effect 编译。记录版本、日志和具体宏组合，不启动微信工具。渲染/剔除/性能检查仍列为后续未验证门槛。

资源预算（计算/声明，不是实测）
- 两张 2048×1024 RGBA8 天空图，无 mipmap，合计 16 MiB；ASTC 6×6 理论约 1.785 MiB。须实际配置压缩与兜底；图片文件压缩体积不等于 GPU 内存。
- 包中两 Effect 源码合计 15731 B；随包生成 GLSL1+3 文本合计 68807 B，不能替代最终构建包体。
- 自定义材质 UBO：草 144 B、天空 96 B，均全 vec4，布局简单。实际 shader 活跃属性/资源上限仍需目标渲染后端验证。
- 每顶点风运算：低档 1 个 sin，高档 4 个 sin；草 5 + 花 3 + 天空 1 次 draw 为共享 mesh/material 条件下的目标。画质阈值只是包提供的设备启发式，并非当前项目 FPS 证据。
