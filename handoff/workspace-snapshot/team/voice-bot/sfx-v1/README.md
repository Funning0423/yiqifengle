# Voice Bot 交付：音效样本 v1（2026-10-09）

作者：Voice Bot（音频）。状态：样本，待 Grok Bot 验收风格。

## 做了什么
用代码合成的 7 个音效（`src/synth_sfx.py`，只依赖 numpy，素材全部原创，没有版权问题）。
风格：F 大调五声音阶的柔和铃音 + 带通噪声做的“风声”，加轻混响，往《起风了》《天空之城》那种轻快治愈的方向靠。

| 文件 | 用途 | 时长 | 大小 |
|---|---|---|---|
| mp3/sfx_match_normal_v0.1.mp3 | 普通消除 | 1.04 s | 8.6 KB |
| mp3/sfx_combo_1_v0.1.mp3 | 连击 1 档（3 音） | 1.25 s | 10.3 KB |
| mp3/sfx_combo_2_v0.1.mp3 | 连击 2 档（5 音） | 1.38 s | 11.3 KB |
| mp3/sfx_combo_3_v0.1.mp3 | 连击 3 档（7 音 + 和弦垫底） | 1.44 s | 11.7 KB |
| mp3/sfx_chest_open_v0.1.mp3 | 开宝箱 | 2.22 s | 18.0 KB |
| mp3/sfx_ui_click_v0.1.mp3 | 按钮点击 | 0.18 s | 1.7 KB |
| mp3/sfx_level_clear_v0.1.mp3 | 过关 | 3.50 s | 28.3 KB |

合计约 88 KB，远低于首屏音频 ≤1 MB 的预算。
格式：mp3，单声道，44.1 kHz，64 kbps CBR。响度 -16 到 -13.5 LUFS，连击逐档变响，真峰值都低于 -1.5 dBTP，不会削波。

## 怎么验证
- `preview_all_sfx_v1.mp3`：7 个音效按 点击→消除→连击1/2/3→宝箱→过关 顺序串起来，一次听完。
- `spectrum_preview.png`：频谱图。
- 重新生成：`python3 src/synth_sfx.py wav`，再用 ffmpeg 转 mp3（`-ac 1 -b:a 64k`）。

## 已知问题 / 待定
- 我没法亲耳试听，响度和频谱是用工具检查的，音色好不好听需要人来判断。
- 文件名暂用 `sfx_*`，等 GGbot 的命名规则定了再改。
- 消除音的尾巴有 1 秒左右（混响），连续快速消除时可能叠在一起；如果接入后觉得糊，我把尾巴缩短。
- 连击目前只有 3 档，更高档可以复用第 3 档或者加音高。

## 命名
按 GGbot《资源目录与命名规则 v1》第 3、4 节：交付文件带版本号 `_v0.1`（样本阶段），接入工程时去掉版本号，放 `assets/bundles/audio_sfx/`，首屏必须的放主包 `main/`。
