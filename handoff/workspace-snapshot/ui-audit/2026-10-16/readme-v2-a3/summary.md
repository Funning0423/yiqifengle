- 真实点击录了三遍：白天 / 夜间 / 白天+切后台 3s。下表是 A3 和 09a1b8e 的对比（详见 logs/home_analysis.txt、cmp_vs_09a1b8e.txt）。

- **满幅采样不是海浪造成的。** 两个版本的峰值都出现在 state:home 之前约 0.37–0.39s，也就是点「回家」后约 50ms：点击音效叠在草地风声上。09a1b8e 那次 1.000 也在同一位置。所以 A3 修不到它；它会不会到 1.0，是随机碰上的。
- **海浪从 0 渐入：没有生效。** A3 三次录制的 waves-play 都是 heard=**0.516**（09a1b8e 是 0.506–0.513）。约 0.8s 后 waves-level 降到 0.02。和旧版完全一样，A3 测试预期的首帧 ≈0.037 没出现。
  - 推测原因：重置条件 `bedOn && !src.playing` 在实际流程里没被触发。过场时海浪是被 update 里自己的 `heard<0.002`（比如 musicBed()≈0）分支暂停的，所以 bedOn 已经是 false，而 vol 还留着旧值。
  - 建议把重置条件改成「每次 play() 之前都 vol=0」，或者在 pause 分支里清 vol，并加 heard 首帧日志来验证。
- 回家后的 RMS 曲线和 09a1b8e 基本一样。切后台那遍里，旧版 +1.0s 有 −20dB 的鼓包，A3 没有（−26dB）。但单次录制，可能是偶然。
