# 小岛之后：场景切换与结局画面设计稿 v1

基准画幅 390×844（2x 出图）。脚本在 `src/`：`kit.py` 是共用工具，`render_prop.py` 是 Blender 渲染，`transitions.py`、`ending.py`、`ending_sheets.py` 生成设计稿。可以重跑：

```
cd ui-design/post-island/src
blender -b -P render_prop.py -- <glb> ../render/x.png 768 <yaw> <elev>
python3 transitions.py --video
python3 ending_sheets.py
```

## 1. 统一转场：「风云擦除」
用一条暖色低多边形云带代替纯黑盖屏。云带顺着风向，从左下往右上横扫，倾角 12°。云边由 26 个半径 36–70pt 的圆形云团组成，边缘做了 1.2pt 柔化（抗锯齿）。

| 参数 | 白天 | 夜间 |
|---|---|---|
| 云面 | 渐变 #FFF6E2 → #FCE4BA，叠 9 片 #FFFCF4 α27% 斜面 | 渐变 #283252 → #3E4668，斜面 α9%，40 颗暖星 #FFE2A0 |
| 盖上 OUT | 0.45 s smoothstep | 同左 |
| 停留 HOLD | 最短 1.10 s。场景加载完才揭开；超过 3 s 后在木牌下方出现三点风纹（Ø6，间距 14，呼吸 0.5 s） | 同左 |
| 揭开 IN | 0.55 s，云带继续往右上散开，不往回退 | 同左 |
| 停留内容 | 3D 载具 200×200pt，中心 y=330，随风右漂 22pt/s，上下浮动 ±5pt（2.6 rad/s），带接触阴影 #3C2814 α24%。<br>目的地木牌 title_plank_3s 176×54，中心 y=470，地区名 22pt Bold #5A3A1E，字距 3，奶白投影 | 木牌乘 NightTint (0.85,0.85,0.92)；载具不乘色 |
| 内容进出 | 盖满后 0.3 s 淡入；揭开前 0.2 s 淡出 | 同左 |
| 输入 | 转场期间整屏吞触摸（和 T-01 的连点问题一致：进关加载期间锁输入） | 同左 |

没有按钮，也不加其他文字。每帧只有一个焦点：载具。木牌是次要信息。

## 3. 结局画面 v2（按 Funning 意见 a–d 改版）
文件（ending/）：
- ending_day.png、ending_night.png：日夜两版
- ending_day_annot.png：标注图
- compare_ending_v1_v2.png：上一版对比这一版
- ending_7sizes.png：7 种尺寸检查
- ending_sway_keyframes.png、ending_sway.mp4：风铃摇摆
- compare_ending_before_after.png：v1 时的现状对比，保留
- compare_ending_v20_v21.png：v2.0 → v2.1 收尾对比

**这一版怎么改的**
- **(a) 去掉大绿山坡**：不再用截图做背景，改用湖畔原始场景 `art/regions/lakeside/blend/lakeside_r5h3.blend` 在 Blender 里重设机位。
  - 机位在湖南岸，Blender 坐标 (10.4,−36.2,2.5)，看向北岸 (10.5,0,8.2)，镜头 20mm，低机位仰拍。
  - 画面中段是湖面、北岸亭子和远山，前景只剩一窄条草地，没有遮挡。
- **(b) 女孩完整入画**：用游戏角色 `region_island/character/chr_b_r5g2_lod0_anim_pass2_INTERIM_s1_grokbot2.glb`。
  - 姿势取 idle_breathing_loop 第 10 帧并定格，头、颈、胸合计抬起 38°，站在湖边仰望风铃。
  - 版式规则：脚离按钮上沿 16pt，头离印章下沿 ≥12pt。高度取「原生高度」和「可用间隙」中较小的，最小 48pt，水平中心在 0.64×屏宽。
  - 游戏里由镜头构图实现，不缩放角色。
- **(c) 风铃挂在木架上，带摇摆**：木架用场景里的 `LK_chime_post.glb`，移到南岸 (9.72,−31.5)，转 120°，放在风铃左后方。
  - 风铃 `LK_windchime.glb` ×1.25，挂在横臂末端（离立柱 1.15m，顶下 0.12m 处为挂点）。
  - 摇摆参数：
    - 绕挂点做正弦摆动。
    - 左右（绕 Y 轴）振幅 ±4°，前后（绕 X 轴）±1.4°（左右的 0.35 倍），两者同相。
    - 周期 3.2 s，循环。
    - 每到最大角时可以配一声风铃音（相当于每 1.6 s 一次，音量随机 ±20%）。
  - 原场景里的风铃本身带动画，渲染时会被覆盖，所以这里重新导入了一只。
- **(d) 橙色木条**：上一版左缘那根橙色木条，是截图里湖畔原风铃架的横臂。改用 3D 场景后它不在画面里了；晾衣绳也已隐藏。木架完整入画，离左边约 60pt。

**不变的部分**
- 「旅程完成」木牌：196×58，24pt；四章印章 44×44，间距 14；按钮「回小岛」240×62；各元素的 y 位置和 v1 相同。
- 7 种尺寸检查全部通过（判定项见表下）。

| 尺寸 | 按钮离边 | 女孩脚到按钮 | 印章到女孩头 | 结果 |
|---|---|---|---|---|
| 320×568 | 40 | 16 | 12 | 通过（矮屏：印章上移 8pt；女孩 48pt） |

矮屏规则（屏幕高 ≤600pt，如 320×568）：四章印章中心上移 8pt，女孩头顶到印章下沿留出 ≥12pt；印章到「旅程完成」木牌仍留 5pt，不重叠。其他尺寸不变。女孩始终在印章和按钮之间，不挪到按钮旁边。

检查脚本 `src/ending_sheets.py` 的判定项：按钮离边 ≥16；按钮在安全区内；女孩完整入画；女孩不压按钮和木牌；**女孩头顶离印章 ≥12pt**（按间距判定，不再只判不重叠）；风铃完整且不压木牌。

**v2.1 收尾（v2 已审批后的两处）**
- **立柱小木板**：它是 LK_chime_post.glb 里一个独立零件（z 1.05–1.75m，贴在立柱 +y 面），从这个机位看像悬空。渲染时只删这一块，模型文件不改，立柱、横臂和底座都保留。
- **夜间单独渲染**，不再用白天图压暗：
  - 太阳改成冷色弱月光：强度 ×0.10，颜色 (0.55,0.65,1.0)。
  - 天空换成纯渐变夜空，从 #0E1D3A 到 #030A1C，不带太阳盘。
  - 关掉体积雾 FX_fog_volume，右上角的光斑就是它对太阳散射出来的。
  - 云的自发光 ×0.15。
  - 风铃灯保留：点光源 #FFC773，180W。
  - 合成时再轻压一档 (0.80,0.80,0.92)，风铃周围的暖光 #FFCE82 α42% 保留。
- 320×568 上印章上移 8pt 保持不变；7 种尺寸重新检查，全部通过。

**夜间**
- 木牌、按钮、印章乘 NightTint (0.80,0.80,0.88)。
- 白天底部 30% 渐暗 #281A0A 0→24%，夜间 #050814 0→39%，不加面板。

**重渲**
- `src/render_all.sh`：在 box 上约 17 分钟（v2.1 只重渲改动的几层，用 `src/render_v2b.sh`，约 9 分钟）。分层渲染：bg 是场景加木架，girl 是女孩，chime 是风铃的 16 个相位。
- 然后跑 `python3 src/ending_sheets.py --sway` 出图。
- 机位等参数在 `src/ending_scene_params.json`。
