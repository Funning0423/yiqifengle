## 铺满规则（首帧 JS 和场景加载层必须一致）
`s = max(W/750, H/1624)`，`dx = (W − 750·s)/2`，`dy = (H − 1624·s)/2`，屏幕坐标 = (x·s + dx, y·s + dy)，元素尺寸 ×s。底图、标志、标题、底轨都用同一套 s/dx/dy。

## 16:9 检查结论
- 16:9 下 cover 上下各裁 145 设计像素，可见 y 145–1479。标志、标题、底轨都在画面里，离边缘最近的是标志顶（距可见上沿 150px）。
- 交接帧对齐：首帧和场景加载层 0%（提示字出现前）逐像素比，平均差 0.86 / 255、99 分位 6 / 255，只剩底图 q80 vs q85 的压缩噪声和元素边缘的 JPEG 振铃；**位置零偏移**。
- 唯一会“跳出来”的是**风车**：首帧按要求只有空底轨，加载层 0% 有风车。建议加载层接手后风车和提示字用 0.2–0.3 s 淡入，交接就看不出来。
