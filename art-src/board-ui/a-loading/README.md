## 底图（占位）
`slices/loading_bg_PLACEHOLDER.jpg` 是 **PM 概念图 A4 的底图**：把原来的标题、标志、进度条和脚注抹掉（cv2 inpaint + 局部模糊），再加一点奶油暖调和底部的浅雾，让提示字看得清。A4 的底图本来就是本作房间的实机截图。**它不是正式美术**，合成图左下角也标了“底图为占位”。正式底图等运镜bot 按房间初始镜头（cameraHome，fov 75）用自有模型渲染，规格：750×1624，柔焦（看得出拱窗、窗外的海和云、女主背影），偏暖奶油色调，**底部 25% 不要放深色或高对比的东西**（进度条和提示字在那里）。上方 18%–32% 是标志和标题，那里最好亮一些、平一些。
没有用任何电影截图或 `wind-rises-apron-ref.jpg`。对比图里的“现状②”是打成 40px 马赛克再模糊后的示意，也只放在 previews 里。

## 标题字体
- 字体：**霞鹜文楷 LXGW WenKai Medium v1.522**（字形基于 Fontworks Klee One）
- 来源：https://github.com/lxgw/LxgwWenKai/releases/tag/v1.522（`LXGWWenKai-Medium.ttf`，sha256 `d4bdeb38…f4e3f6`）
- 协议：**SIL Open Font License 1.1**，可以商用。全文在 `src/OFL.txt`。我们只把字转成矢量路径、再栅格化成 PNG，**游戏包里不带字体文件**，这属于 OFL 允许的用法。保留字体名“霞鹜 / LXGW”的限制只针对分发改过的字体文件，跟我们无关。建议在关于页或致谢里写上字体名。
- 原创处理：用 fontTools 把 5 个字的轮廓取出来重新排版（逗号的字距收紧）。文字外面加了一圈 7px 的深青描边（#2D555B，55% 透明）、奶油色的竖向渐变填充（#FFFDF6 → #F8E5C4），再加一层深青的柔和投影。另外画了一条原创的“风线”：从“起”的下面掠过，在“了”的后面卷起来，浅青色 #BDE9E6，跟标志上的风线呼应。
- 提示字（“风从海上来……”）在预览里用 Noto Sans CJK SC（OFL）渲染。游戏里用系统字，0 字节。

## 接入建议（给 GGbot，等 Funning 确认以后）
1. 加载页节点放在启动场景，**底图和切图放主包**（例如 `assets/startup/`），不要放在 `resources` 分包。这样第一帧就有图，不会闪纯色遮罩。
2. 布局（设计分辨率 750×1624，或者按 390×844 逻辑分辨率除以 1.923）：底图 cover 铺满；标志 (393, 316)；标题 (375, 452)；进度条底轨的左边 x = 127（包括 8px 的内边距），中心 y = 1292；提示字的中心 y ≈ 1356，深青灰色 #3F5E63，字号 28px（14 逻辑像素）。
3. 进度：`bar_fill` 用 FILLED、HORIZONTAL 填充，`fillRange = 8/496 + p*(480/496)`。风车的 x = 底轨左边 + 8 + 480·p，y 跟着飘带的波浪走，偏移 `5*sin(2π·(480p)/135)` px（向下为正）。风车一直转，大约 1 圈 / 1.2 s。p 只按 `StartupReadyGate` 的三个真实阶段推进（海岛 / 角色 / 房间各 1/3，阶段内缓动），**不能有假进度**。三段的提示文案分别是“风从海上来……”、“她在窗前坐下……”、“灯塔小屋准备好了”。
4. ready 以后，整个加载页用 UIOpacity 在 0.6–0.8 s 内淡到 0（ease-out），淡完再 `active=false`，不要硬切。“向左轻扫”这个提示等淡出结束再出现。
5. Cocos 启动画面：能关就关（`useSplashScreen:false`）。关不掉的话，logo 换成 `splash_option_same_image.jpg`（同一张图，backgroundColor 取底图的主色），`totalTime` 降到最小。要删掉的东西照 PM 文档 §3 的清单。

## 需要决策
1. **Cocos 启动画面关不掉的话**，“同一张图”会再占一份底图的体积（现在占位版 34,863 B，正式版估计 50–90 KB），整页加启动画面会超过 120 KB。建议优先关掉；关不掉的话，要么接受启动画面算在预算外，要么把加载底图压到 ≤ 60 KB。
2. 标题现在是霞鹜文楷（楷体手写感，偏治愈）。如果更想要 A4 那种黑体的稳重感，可以换成思源黑体 / 站酷系（都是 OFL），换一下字体参数就能重出。
