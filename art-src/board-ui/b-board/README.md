## v3 修订（Funning：其他棋子和道具向草莓、橡果看齐）
**为什么草莓和橡果显得立体**（在 v2 原始渲染上量的，192px 切图）：
1. **造型是立起来的整块体积**：高约 127–131px（占切图 2/3），宽高接近 1:1，像一个坐在格子里的果子；青叶、白花在 v2 是正对相机的薄片。
2. **侧面和背光面露得多**：主光从左上前方来，圆形体积的右侧和下半部转到背光，**暗部（亮度低于亮面 75%）占 47–80%**，明暗比（亮 95 分位 / 暗 5 分位）**2.6–3.3**；v2 青叶只有 9% / 1.58，白花 5% / 1.34。

- **青叶选哪个？**（v3 时我推荐 B；**Funning 最终选了 A**，见 v3.1）
  - 外形：唯一一个“盆 + 莲座”的轮廓，梯形底座 + 放射状尖叶，和圆形的草莓、橡果、蓝莓、扇形的扇贝、五瓣的白花都不一样；灰度下也能靠外形认出来（见 `leaf_AB_gray.png`）。
  - 立体感：盆是实心体积，叶片三层叠放，暗部 68%、明暗比 3.48，跟草莓、橡果同一档，比方案 A 强。
  - 没选青苹果：青苹果是“圆身体 + 顶上一根柄 + 一片小叶”，和草莓（圆 + 顶部绿萼）、橡果（圆 + 顶上果柄）轮廓太像；绿色盲下青苹果的黄绿和橡果的黄棕会更接近。
  - 代价：它不再是“叶子”，如果关卡文案、目标图标里写的是“青叶”，需要 PM 跟 GGbot 确认改名（比如“多肉”），目标牌上的小图标也要换。方案 A 不需要改任何文案。
- **方案 A 的局限**：叶子本身是薄片，就算加厚、对折，明暗比也只到 1.79，仍然低于草莓、橡果；暗部比例已经到了 51%。
- **白花的局限**：白色本身的明暗比只能做到 1.4 左右（再压暗就不白了），立体感主要靠杯形轮廓、凸起花心和底下的绿萼。

## 设计要点
- **托盘**（v2 已改浅）：浅木底板 + 浅色板条，外圈一整圈扫掠成型的圆角浅木框，四角浅色圆榫；v1 的小扇贝/海星装饰已去掉。原来的深绿粗边框去掉了。
- **棋子底座**：浅灰木色圆角方块（v2：`tileL1` / `tileL2` 交替，比 v1 更浅、更低对比），厚 0.1，带倒边和内圈浅槽，有柔和投影，跟 T9 路牌的奶油面板是同一种做法。
- **6 种棋子**（身份不变，type0–5；v3 造型见上面“v3 修订”）：草莓（红色心形 + 黄籽 + 绿萼）、青叶（定稿：方案 A 加厚 V 形卷叶，v3.1 加强）、蓝莓（三颗，带深色花萼）、小白花（五瓣 + 金色花心）、橡果（浅色帽 + 深色果）、扇贝（青色扇形，带棱）。每种外形不同，明暗分布也不同。绿色盲模拟下，草莓和橡果的色相会接近，所以把橡果改成了“浅帽深果”，靠上下明暗对比来区分（见 pieces_sheet 最后一行）。
- **特殊块**：横排 = 横向风丝带，奶油底、青色中线，两端有青色箭头；竖排 = 同一条丝带竖过来；炸弹 = 四色纸风车（橙 / 蓝 / 奶油 / 青，跟 (a) 的进度条风车同一套颜色）垫在棋子后面，棋子缩到 80%，风车建议约 1 圈 / 3 s 慢转。丝带和风车都会伸出棋子轮廓，50px 下也认得出来。
- **障碍**：苔藓 = 整格软苔藓垫，带小白花，压在棋子下面；树根 = 两根粗根交叉成 X，压在棋子上面；贝壳盖（v3 重做）= 一只比格子大的偏灰浅色扇贝（调色板 `grey` #C8C8C6，无青色），平平地盖在格子上，被格子边裁掉，只露出上半边：7 条宽棱放射、顶部规整的波浪弧边、铰合处和耳朵在格子外面看不到。2 层 = 完整盖子；1 层 = 同一个盖子加两道顺着棱沟的深色裂纹。结构和扇贝棋子一样，但棋子是立着的小青色扇贝、带落地影，盖子是平盖整格的大灰贝壳，对比见 `shell_lid_compare.png`。
- **HUD（简洁版）**：顶部只留**左上一个暂停钮**（44×44pt，木圆盘 + 奶油面 + 两根木条）和**居中的一块关卡信息牌**（214×60pt，放在胶囊那一行下面，第一行是关卡名，**全屏只出现这一次**；第二行是目标棋子雕件 + 剩余数 ｜ 沙漏 + 剩余步数）。右上角 x≥253pt、y 51–83pt 这块（胶囊加左边的系统图标）什么都不放。
- **道具**：最多 3 个，木底座 + 低多边形道具雕件（星光 = 金星嵌青石，风语铃 = 石板蓝铃 + 纸签，潮汐瓶 = 青玻璃瓶 + 软木塞），右上角是奶油圆牌，深棕数字。数量为 0 时用 `Sprite.grayscale`、透明度 55%，角标换成 “+”。没有道具时整栏收起。道具下面不再常驻名字。
- **背景**：灯塔顶露在左上，右上是云，中间被托盘挡住，底部是浅滩和海浪。整体柔焦，并加 14% 浅雾，让托盘跳出来。棋盘上下留白都比现在多。
