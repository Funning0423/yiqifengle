## 做了什么
- 脸：新四边形球拓扑（768 三角），圆润下颌、小鼻尖；法线按平滑椭球导出（二次元柔和明暗，没有鼻子/下颌折痕）。脸部贴图重画：V12 风格棕色大眼+高光、两侧细眉、小嘴、淡腮红，不再烘焙阴影。脸部 UV 正面平面投影，后脑和下巴底面映射到纯肤色区。
- 脖子：缩细（半径 33–36 mm，原来约 57 mm），权重 chest→neck→head 渐变（和原来一样用这三根骨）。
- 立领：新加黄色立领（160 三角），盖住原上衣领口，权重 chest 1.0 → 顶部 chest 0.7 / neck 0.3。
- 头发：波波头主发壳（768 三角）+ **刘海独立一片**（180 三角）+ **后发梢独立一片**（144 三角，从她左侧绕后脑到右侧，末端往里收）。
- 帽子：改平顶硬草帽（672 三角），粉色帽带，向后倾 10°；帽冠尺寸按头发自动适配（不穿发）。
