## 改动（数值）
### 袖子（每只 1000 三角面，r1 是 768）
- 袖筒半径（m），r1 → 本版：上臂中段 0.053 → 0.059（+11%）；肘上 0.049 → 0.056（+14%）；前臂上段 0.0435 → 0.050（+15%）；前臂中段 0.0445 → 0.052（+17%）；克夫前的堆积 0.043 → 0.056（+30%）。再加上下面的垂坠量，背面和外下侧实际又放松 7–16%，外侧轮廓整体放松约 18–30%。
- 垂坠：向“外侧 0.8 + 背面 0.2 + 向下 0.4”方向额外鼓出，幅度沿袖长是：肘 7%、前臂中段 16%、克夫前 12%。上臂背面收回 10–14%，前臂正面收回 6–14%，这两处是为了让开围裙。贴身体的内侧压平 45–70%，内侧褶皱只保留 10%。
- 褶皱：两组斜向褶加一组纵向垂褶，幅度 9–13%（r1 是 7–10%）；肘弯处另有横向压褶 7%。法线取自褶皱放大 2 倍的同拓扑副本。另外按褶皱深浅在 UV 上采样黄色渐变条，凹处深、凸处亮。
- 克夫：半径 0.034 → 0.0355，不勒手腕。克夫上方有两圈抽褶堆积，幅度 5% 和 10%（10 瓣）。
- 权重：肘部混合宽度 ±6 cm（r1 是 ±3.5 cm）。袖山前 4 圈从躯干权重渐变过来，摆臂时不会扭成麻花。

### 手（每只 448 三角面）
- 整体放大 1.30 倍（r1 是 1.0，r2a 是 1.20）。掌宽 0.056 → 0.0594（×1.30 后约 7.7 cm），手指长度 ×1.18×0.95×1.06（约 +19%），指径 ×1.05。从手腕到中指尖约 18 cm，约为身高的 10.5%，和 V12 同比例。
- 手掌：截面指数 0.85 → 1.0（更圆），厚度 ×0.82，腕部收窄到 0.038。手指弯曲减到 r1 的 64%，放松微握。拇指往掌心收 4 mm。
- 整只手沿掌心法线朝身体外侧偏 3.2 cm（越靠近指尖偏得越多），这是为了让开围裙。

### 小腿（每条 364 三角面，14 段）
- 旧网格从膝盖往下删掉，换成直的锥管。半径（左右/前后，m）：膝 0.041/0.044、0.43 处 0.039/0.042、0.35 处 0.0365/0.039、0.27 处 0.033/0.035、0.19 处 0.029/0.031、踝 0.026/0.028。没有小腿肚。原来小腿肚最宽处半宽约 0.049/0.050，现在收了 20% 以上。
- 黄裙裙摆整体上提 3.5 cm（z 0.38 → 0.415，到 z 0.62 处衰减为 0），露出的小腿更长。这只是顶点位移，DRESS 的拓扑、权重、骨骼都没动，围裙也没动，对下一轮裙子和围裙分层的影响很小。
- 权重：膝部 thigh→shin 在 z 0.46–0.55 平滑过渡，踝部 shin→foot 在 z 0.065–0.14 平滑过渡，和鞋共用同一个权重函数。

### 高帮鞋（每只 432 三角面，16 段）
- 鞋口高度 z 0.161，脚踝骨大约在 0.08，鞋口高出 8 cm。鞋口内侧向里翻 2 cm，形成厚度。
- 鞋口贴脚踝：半宽 0.029、前后 0.031/0.033；踝上最窄处半宽 0.030；踝骨处放到 0.037，形成一点收腰，不再是直筒。
- 鞋头：前半段改用椭圆截面（指数 1.0），鞋头收窄 30%。长度 0.15 m（r2a 是 0.155），最宽处半宽 0.044（e60 约 0.06）。
- 颜色沿用 e60 鞋子：鞋面 (168,81,53)，鞋底深棕 1.2 cm。
- 权重：鞋帮跟随 shin，鞋头和鞋底跟随 foot，在踝部平滑过渡。走路第 6 帧的侧面看，踝部弯折自然（见 06 图）。

结论：
- **walk v2**：0 穿插，最小间隙 6.8 mm（右手→围裙），全部 ≥ 6 mm。
- **door_reach** 第 4 帧：右手伸向门时，右前臂内侧和围裙上沿有 15 个三角对轻擦，顶点间隙 2.8 mm。袖子放松之前是 0。我在建模这边已经把肘内侧压到 70%，再压袖子就会变形，所以建议动画bot把这一帧的右肘外展 2–3°，或者等下一轮围裙分层时一起处理。
- **sit_down / sit_hold / stand_up**：袖子和裙子、腿和裙子的穿插，e60 原版就有（腿→裙 e60 是 218，本轮 192；袖→裙和袖→围裙和 e60 相当），根源是坐姿的裙子没有解算，留给下一轮裙子和围裙一起处理。
- 旧的 walk_loop 和 wind_sway：0 穿插。

## 已知问题
1. door_reach 第 4 帧右袖内侧和围裙轻擦（见上），需要和角色动画bot对接。
2. 坐姿下袖子、腿和裙子穿插，是 e60 就有的问题，下一轮裙子和围裙分层时一起解决。
3. 手背从外侧看还有点方，手指是简化的 7 边管，没有指甲和关节细节。
4. 袖褶的浓淡靠 UV 采样渐变条：游戏里换材质或改光照时要保留这张贴图。法线褶在 Workbench 下比较弱，要以引擎里的效果为准。
5. 裙摆上提只改了顶点，裙子本身的布料细节留到下一轮。
6. 头部没动（head-r2）。头部以后改用 AI 生成，换头时要重新对接立领和脖子。
