# 上身 R1：肩、手臂、袖子、衣身、手（本轮迭代 3 次）

GLB：chr_b_r5g2_body-r1_TEST.glb（e60 骨架和动画 + 头 R2 + 新上身）、chr_b_r5g2_body-r1_walk-v2_TEST.glb（walk v2 动画）。
工程：body_r1_work.blend（每轮存；iter0 / iter3 / final 是各轮快照）。参数在 data/params.json，脚本 scripts/build_body.py，一键 scripts/run_all.sh。

## 袖型确认
V12 是长袖：肩头抽褶微鼓，上臂比较合身，前臂到袖口前略蓬，用克夫收口。按反馈做成：肩头到上臂中部明显鼓起的泡泡袖（最大半径 5.2 cm，袖头有抽褶，下缘收口），上臂收窄，前臂往腕部收窄，克夫前保留 V12 那样的一点蓬度，克夫高 4.4 cm，上沿有压线，看得清。

## 改动
- 肩线：袖子改成"装袖"结构。第 0 圈直接贴在衣身侧面的袖窿上（倾斜的袖窿面，向下沿 ray cast 贴合），后面 4 圈逐步过渡到袖筒并往外鼓。袖子是从肩里长出来的，不再是一根圆筒插进肩里，肩线没有台阶。衣身肩部改成溜肩（领口到肩点斜度约 28°），和 V12 一致。
- 去掉了腋下的方块翻片（旧上身多边形整片删除后重建）。
- 领口：独立的立领，抬高到 1.452 m；衣身顶部干净地收进领子里。衣褪（胸前白色护片）和肩带是独立几何体，贴着衣身外扩 1.2 mm。
- 手：放松微握。四指弯曲依次加大（小指最弯），拇指往下贴向食指。
- 蒙皮：肘部和腕部用渐变权重（肘部前后各 3.5 cm，腕部约 2.2 cm）；衣身加 spine/hips 渐变权重；肩部 0–55% 渐变到 upper_arm。袖窿圈第 0 圈直接用衣身的权重，后面 3 圈逐步过渡到袖子的权重，接缝两侧权重相同，抬臂时不会裂开。28 根骨不变。

## 穿模（QA 脚本 qa_clash.py，所有动作逐帧）
- walk v2：袖到围裙最小 7.0 mm（≥6 mm 求解余量，e60 是 7.8），手到围裙 9.1 mm，袖到裙 17.7 mm，没有穿插。
- idle、wind_sway、door_reach、walk_loop：没有穿插。
