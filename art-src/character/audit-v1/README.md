## 3. 问题清单（★ = 用户点名的重点）

### ★ 脸 / 头（图 03、03b、10、11）
1. 脸是“前投影贴图+三角面片汤”（3,074 面）：五官全部画在一张正面投影的 1024 贴图上（图 09），侧面和俯视时五官拉伸、变形；左右眼被头发切掉不一样多。
2. 鼻子是一个尖楔，3/4 和俯视下像突出的喙（03 3/4、03b 俯视）；脸颊、下巴表面坑坑洼洼（线框里能看到噪声），不是二次元那种圆润干净的面。
3. 发际线是贴图边缘：额头露出一块不规则的皮肤，边缘锯齿、带蓝色杂点（贴图里的锯齿边，图 09）；没有刘海，和 V12 的斜刘海、齐耳波波头差很远。
4. 头发是一整个“头盔”（4,134 面），侧面看不到耳朵和脸颊线，后脑过大；颜色只有一个材质色，没有任何明暗层次。
5. 眉毛只有一侧一条细线，位置偏高；嘴是一条很小的线；眼睛有烘焙进去的阴影，和实时光照叠加后显脏。
6. 脖子太长、太粗，而且是一段“肤色罗纹高领”（贴图拉伸成竖条纹）；V12 是黄色立领一直到下巴下方。
7. 帽子：V12 是平顶硬草帽（boater），当前是斜顶、帽檐下垂的渔夫帽形状，帽檐边缘锯齿（03 侧面）。

### ★ 手臂 / 袖子（图 04、05、05b、12）
8. 袖子是一根直筒，没有 V12 的泡泡袖（袖山微蓬、袖口上方收褶）和袖口克夫。
9. 袖山和上衣不连续：上臂顶端是一个带“盖子”的圆筒插进肩里，肩部有台阶和凹陷（05 肩/袖山、腋下）；walk-v2 摆臂时这个接缝更明显（12 肩部列）。
10. 上衣在腋下/腰侧有方块状的翻片（06），在正面全身图里从围裙两侧露出（01 正面，袖子内侧）。
11. 权重刚性：BODY 最多 2 根骨，肩部 chest↔upper_arm 过渡只有 ~135 个顶点，肘部 ~160 个，摆臂时肩和肘是“折”而不是“弯”。
12. 手：每只 1,036 面（比整个上臂+前臂还多），手指细长张开像爪子（05b），整手只绑 hand 一根骨（没有手指骨，所以必须把手指形状直接做成放松微握的样子）。
13. 袖口是单层开口筒，能看到边缘厚度为零；袖长到腕骨以下，正好盖住一截手背。

### 上身 / 裙子 / 围裙 / 其他（图 06、07、10、12、13）
14. 围裙胸片画在上衣贴图上，没有厚度和边缘；没有肩带和背后的竖带（10 背面对比很明显）。
15. 围裙下摆比黄裙宽、而且是硬直的三角梯形，侧面像一块纸板（07 侧面）；V12 的围裙比裙子窄、下摆是圆角。
16. 上身只绑 chest，spine/hips 没权重：走路的骨盆扭转（±5°）和胸反扭（6.5°）全靠上衣和裙腰之间的接缝吸收，腰部会露缝/穿插（静态看不出，动作里要查）。
17. 蝴蝶结从侧面看是一个“勺子”形大环，系带是两根细线离身体好几厘米（07、01 侧面）。
18. 鞋边缘有白色袜子贴图渗色（07 鞋），鞋形状可以但偏厚。
19. 整体网格没焊接（BODY 415 块），平滑着色下会出现硬接缝；而且凭空多出 44% 顶点，浪费包体。
20. 贴图分辨率与用途不匹配：帽子 1024² 占 124 KB，裙子大部分是平涂黄色却用 1024²。

## 4. 精修方案

### 4.1 原则
- **骨骼 28 根、名称、顺序、父子关系、rest 姿势、inverse bind matrix 一律不变**；网格节点名（LOD0_G2_APRON/BODY/BOW/DRESS）、材质名（6 个）、贴图名不改，保证 Cocos `.meta` 的 subMeta（如 BODY mesh `ee698`）和 prefab 引用不变、角色动画bot 的 splice 工具直接可用。
- 体型比例沿用当前骨架（交接文档明确：不要按 AI 图“再高一点”拉骨架）；V12 只用于造型、服装、脸部风格。
- 风格：低多边形、面要干净圆润，配合小岛渲染那种柔和的平光；不加描边、不做夸张 Q 版。
- 所有工作在 `previews/角色建模bot/` 下的 `.blend` 里做，验收前不进 worktree、不提交。

### 4.2 步骤
1. **基线和参考板**：导入 e60，把 V12 正/侧/背作为参考平面按身高对齐（只对齐头、肩、腰、裙摆、脚的比例线）。锁定骨架。
2. **头部**（P0）：重做四边形拓扑的脸（约 1,200 三角），眼眶/嘴有环线，鼻子改成小而柔的鼻尖；UV 按正面圆柱展开，重画脸部贴图（V12 风格的大棕眼带高光、两侧细眉、小嘴、淡腮红），不再烘焙阴影。眼睛放在独立 UV 区，以后可以用 UV 偏移做眨眼（不需要新骨骼）。
3. **头发**（P0）：重做波波头 + 斜刘海（约 1,800 三角），发际线由几何体遮住，内侧加一层深色内壳避免透光；用顶点色/小渐变做头顶到发梢的明暗。全部绑 head（和现在一样）。
4. **帽子、脖子、领子**：帽子改平顶硬草帽（约 600 三角，帽檐边干净）；脖子缩短收细，换成黄色立领。
5. **上身 + 袖子**（P0）：上衣重做为一整块连续的壳（去掉方块翻片），袖窿一圈 10–12 段与袖子共边（不再插筒）；袖子做泡泡袖：袖山微蓬、上臂到前臂自然收、袖口上方收褶 + 3–4 cm 克夫，袖口有翻边厚度；肩 3 圈、肘 3 圈、腕 2 圈过渡环线。
6. **手**（P0）：每只降到约 450 三角，手形缩小，手指做成放松微弯、中无名小指略并拢的姿态（没有手指骨），掌心朝腿。
7. **裙子和围裙**（见 4.5）。
8. **UV 和贴图**：能用的旧贴图（裙、鞋、袜）重新投影烘焙到新 UV；保持 5 张图名不变，但降分辨率（见 4.3）。
9. **蒙皮**（见 4.4）。
10. **导出与自检**：脚本比对新 GLB 和 e60 的 joints 名称/顺序/IBM（误差 <1e-6）、7 段动画通道原样、mesh/material/image 名称一致；算原生包体。
11. **QA 渲染**：同 V12 三视图对比、游戏俯视机位、walk-v2 各相位、sit/door 关键帧；交角色动画bot 跑他们的穿模脚本；全部通过后交项目经理。

### 4.4 对蒙皮和穿模结果的影响
- 骨骼和 rest 姿势不变 → 7 段动画曲线本身不用改，**但所有 4 个网格拓扑都会变，权重必须全部重新生成**，角色动画bot 之前的穿模结论（腿↔黄裙 7.8 mm、腿↔围裙 15.9 mm、后片 39.7 mm、手臂↔裙/围裙 7.9 mm、手臂↔躯干 2.5 mm）对新模型**都要重测**。
- 权重做法：在 rest 姿势下，对新网格加 Data Transfer 修改器（源 = e60 对应旧网格，Vertex Data → Vertex Groups，映射用 Nearest Face Interpolated，层用 All Layers / By Name），应用后：
  - 腿、鞋、头、帽子、头发：直接沿用传递结果（这些部位旧权重本身没问题）。
  - 肩、肘、腕：在传递结果上手动重画加宽过渡带（肩 chest/upper_arm 3 圈渐变，肘 2–3 圈，腕 2 圈），Smooth 2 次，Limit Total 4，Normalize All。
  - 上身：新增 spine 和 hips 的权重（腰部 hips→spine→chest 渐变），让上衣跟骨盆扭转一起走。**这会改变所有动作里上身的变形**，是唯一“行为变化”的点。
